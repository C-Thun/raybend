本版重点在编辑侧：**编辑区（可分层调整）**与**多层 LUT 链**落地，控制点的取样与容差按真照片重做；
浏览侧补上**目录管理与照片移动**、**右栏元数据就地编辑**；另外会记住窗口位置，并只允许单实例运行。

### 编辑：编辑区（分层）

- 编辑栈从「一层参数」变成可分层的**编辑区**：一个**默认层**（全图效果与镜头/降噪/曲线这类全局阶段的宿主，不可删）
  加若干**全图**层与**控制点**层，最多 32 个（默认层不计）。
- 列表自上而下即计算顺序，新增层追加在末尾。每层有名字（≤30 字符）、启停开关、删除与拖动排序；
  拖动时有整行跟随与落点占位。
- **控制点**：在图上点一下取一个种子（可拖动改位置），用一条引线表达范围 —— **引线越长，容差越大**；
  权重改为**亮度与色相分别比较**，同色不同受光面的物体能被一起选中。
- 修正竖拍 RAW 的控制点取样方向（此前方向取自解码器，个别机型会把天空取成墙面）；
  小范围取样改用中位数，避免噪点污染种子。
- **Space** 在默认层与当前层之间切换；默认层之外不显示全局阶段页签（避免误以为镜头/降噪可以逐层设）。
- 编辑器工具栏重排：撤销在左、重做在右，重置与「显示控制点」的眼睛开关收进中段，「拟合」改为图标 + 文字。
- 「预设」面板从右栏搬进左列（编辑区 / 定稿 / LUT / 预设 四选一），左列底部固定「总览 / 信息」。
- 右栏新增**色盘**页位（与曲线、色彩管理并列）—— 本版只有位置，尚未提供调色控件。

### 编辑：多层 LUT

- LUT 从「单张叠加」改为**多层链**，最多 8 层：每层可调强度、单独启停、拖动排序。
- 预设可以保存与套用**整条链**；套用超出层数上限时多余层不加入，并提示一次。
- 层强度为 0 时点开关，强度回到 100%（不再出现「打开了却不生效」）。

### 浏览：目录与移动

- 左列目录条常驻小工具栏（新建 / 删除），按选中目录决定是否可用；删除前做**浅检查**：
  这一层还有看得见的子目录或照片就不允许删，`.xmp` 残留与空 `_RAW/` 不阻止删除。
- 目录点一次选中，再点一次回到「相片库根目录」状态（回收站同理：再点退出回收站）。
- **把照片拖到目录上即可移动**：落点高亮，悬停 1 秒自动展开子目录。
- `Ctrl+X` / `Ctrl+V` 剪切粘贴（不支持 `Ctrl+C`），`Esc` 取消；剪切中的缩略图压到 70% 并计入提示带。

### 浏览：右栏元数据可直接改

- 作者、描述、地点等文字字段改为**就地编辑**：失焦即写库并回填。
- 输入时给出建议：最近输入过的值 ∪ 库内已有的值，`↑`/`↓` 选择、`Enter` 采用、`Esc` 只关列表。
- 地点支持**按 GPS 自动填入**（内置离线城市表，不需要联网）。
- 照片没有 GPS 坐标时，GPS 行整行不显示（此前会显示成看似可编辑的空行）。

### 外壳与窗口

- **记住上次关闭时的窗口位置与大小**，下次启动回到同一块屏幕的同一位置；
  关闭时最大化就在该屏最大化，最小化关闭则不记录。
- **单实例**：已经有一个窗口在运行时，再启动只会把已有窗口叫到前面，不再开第二个。
- flowbar 新增**功能提示带**（一句随场景变化的操作提示，可在设置里关掉）。

### 修复

- 空格键切层不生效。
- 大图缓存的清理在同修改时间下按名字定序，避免偶发删错导致重新生成。
- 提示气泡默认朝上（上方放不下才翻到下方）。
- 右栏页签名 `Color wheels` 简化为 `Wheels`；层名条改为平化样式。
- 导出右栏改版：段标题统一为「主色竖条 + 加粗」，段名恒为「当前预设」，名称 / 格式 / 文件同名三行改为字段名与控件同行。

### 已知限制

- 色盘、完整曲线编辑与色彩管理仍在打磨，右栏对应页位目前是**占位**。
- 编辑区中只有逐像素类调整可以分层；镜头校正、降噪、锐化、局部色调、基础曲线、LUT 与几何属于**全局阶段**，只挂在默认层上。
