RayBend 隐私说明

照片、RAW 解码、编辑与相片库管理在本机完成。应用没有遥测、账户登录、自动上传照片或自动发送诊断的机制。非破坏性编辑保留原图；导入、导出、移动等您明确选择的文件操作会写文件。

更新是主动操作。检查向所选服务器请求更新 JSON；服务器通常能看到 IP、请求时间、版本/平台请求与一般网络元信息。官方下载由 GitHub 或官网托管，自定义源则由您选择的服务提供者处理。下载需要通过配置公钥的签名校验；可以关闭更新或为第三方构建设置自己的源和公钥。商店安装的更新由商店提供。不会向更新服务器发送照片、EXIF、库内容或个人目录。

关于窗口复制的诊断摘要只含软件版本、通道、构建时间、commit 和 WebView 版本，没有本地路径或照片。它不会自动发送。您自行分享的截图、日志、错误清单与样本可能包含私人数据，请在发送前检查。

官网访问及 GitHub issues/下载的隐私规则由相应服务提供者决定。本说明对应当前源码；新增联网行为必须同步更新这份说明和应用内文案。
