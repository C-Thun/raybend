RayBend 隐私说明

照片、RAW 解码、编辑与相片库管理在本机完成。应用没有遥测、账户登录、自动上传照片或自动发送诊断的机制。非破坏性编辑保留原图；导入、导出、移动等您明确选择的文件操作会写文件。

更新检查在启动后自动进行一次（可在更新设置里关掉），您也可以随时手动检查。检查只向稳定源请求一份更新清单（下载好一个更新包后，下一次启动会再请求一次清单，用于确认这个包仍然是最新的）；服务器通常能看到 IP、请求时间、版本/平台请求与一般网络元信息。安装包由 GitHub Releases 托管。**下载的安装包必须通过内置公钥的签名校验才会保存到本地**；下载在后台进行、失败或中断不打扰您（下一次启动会静默重试一次）。不会向更新服务器发送照片、EXIF、库内容或个人目录。商店安装的更新由商店提供。界面不提供换源与换公钥的入口；第三方构建按 AGPL-3.0 在源码层配置自己的源与公钥。

关于窗口复制的诊断摘要只含软件版本、通道、构建时间、commit 和 WebView 版本，没有本地路径或照片。它不会自动发送。您自行分享的截图、日志、错误清单与样本可能包含私人数据，请在发送前检查。

官网访问及 GitHub issues/下载的隐私规则由相应服务提供者决定。本说明对应当前源码；新增联网行为必须同步更新这份说明和应用内文案。
