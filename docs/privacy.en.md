RayBend privacy policy

Photos, RAW decoding, editing and library management run on your device. The app has no telemetry, accounts, automatic photo upload or automatic diagnostic submission. Non-destructive edits preserve originals; import, export, move and other file operations write files as you explicitly choose.

Update checks are initiated by you. They request an update manifest from your chosen server, which can normally observe your IP, request time, version/platform request and ordinary network metadata. Official downloads are hosted by GitHub or the website; a custom source is provided by the service you choose. Downloads must verify with the configured public key. You may disable updates or configure your own source and key for a third-party build. Store installations use Store updates. No photos, EXIF, library contents or private directories are sent to update servers.

The diagnostic summary you can copy in About contains only build and runtime details, without local paths or photos. It is not sent automatically. Logs, screenshots, exported error lists and samples you choose to share can contain private information; review them first.

Website visits and GitHub downloads/issues are also governed by those service providers. This policy describes current source behavior; new network features must update this document and app text.
