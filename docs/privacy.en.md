RayBend privacy policy

Photos, RAW decoding, editing and library management run on your device. The app has no telemetry, accounts, automatic photo upload or automatic diagnostic submission. Non-destructive edits preserve originals; import, export, move and other file operations write files as you explicitly choose.

Update checks run once at startup (this can be turned off in update settings) and whenever you ask. They request an update manifest from the stable source; after an update finishes downloading, the next launch requests the manifest once more to confirm the package is still current. The server can normally observe your IP, request time, version/platform request and ordinary network metadata. Installers are hosted on GitHub Releases. A downloaded installer is saved only after its signature verifies against the built-in public key. Downloads run in the background and never interrupt you on failure (the next launch retries once, silently). No photos, EXIF, library contents or private directories are sent to update servers. Store installations use Store updates. The UI exposes no source or key overrides; third-party builds configure their own source and key in source form under AGPL-3.0.

The diagnostic summary you can copy in About contains only build and runtime details, without local paths or photos. It is not sent automatically. Logs, screenshots, exported error lists and samples you choose to share can contain private information; review them first.

Website visits and GitHub downloads/issues are also governed by those service providers. This policy describes current source behavior; new network features must update this document and app text.
