RayBend 使用说明

开始使用
在导入工作区新建相片库，或选择包含既有 .raybend 库的目录登记已有库。目录错误、只读或库损坏会在探测/提交处报告；不要为了跳过错误而删除库文件。库注册表读失败时不会显示“没有库”的欢迎提示。

导入与浏览
选择来源与目标库、检查排除项与命名规则后开始导入。导入复制/移动行为以您选择的方案为准；遇到失败查看本批错误清单。浏览中可评级、打标、筛选、看图；拍摄信息上方可切换当前显示定稿。该选择只影响本次浏览显示，不改写 latest；离开浏览或切换目录后恢复 latest。Ctrl+K 查找动作及当前快捷键，快捷键设置可更改键位。

非破坏性编辑
编辑参数与定稿存在相片库中，不直接覆盖原照片。等待保存完成再退出或安装更新。完整色彩管理属于后续阶段，当前版不能作为颜色校准完成的证明。

导出
导出工作区按相片显示 latest、命名定稿与 SOOC；同内容的定稿合并显示。选中需要的定稿，先新增或变更并保存预设，再入队和开始。未保存的设置不能开始。普通导出格式为 WebP、AVIF、JPG、PNG；PNG 不显示质量设置。可选原尺寸、百分比或最大边缩放，以及目标目录和命名模板。默认 Enter 将选择入队，Ctrl+Enter 开启/停止当前预设；Ctrl+K 可查看或修改实际键位。

最多同时开启四个预设，各自排队后台输出；空队列保持开启并等待新项。停止保留队列，已在执行的照片完成后停止；失败原因与重试在队列条目中。切工作区不停止输出。队列和开关只存内存，退出后丢弃；预设设置保存到设备。重置需确认，并清除队列、开关与处理记录；它不强行打断已在执行的出图。执行前定稿失效会跳过，源文件变化会报错。写出的文件不会覆盖原照片；同名目标按序号避让。

送到外部编辑器
在浏览工具栏右侧打开外部编辑入口。使用本次浏览当前显示的定稿，选择已登记应用与输出目录，再确认。添加应用会探测支持的已安装候选；找不到便携版时可手动选择 exe。应用与上次输出目录会记住，卸载后的失效应用会报告并清除登记。

输出为原尺寸 RGB16 TIFF，复用导出渲染、几何与元数据管线；写出后唤起外部应用。关闭弹窗或切工作区时继续后台处理；取消在阶段边界生效，已经写出的 TIFF 保留。若外部程序打不开，仍保留 TIFF 路径，可自行打开。本流程是单向交接：不自动取回、不把 TIFF 登记为库内照片、不改写原源或 latest。元数据按输出管线支持的字段保留，并不保证完整复制 MakerNote、嵌入缩略图或 ICC；色彩管理仍属后续阶段。

安装与更新
官网下载通过官方 HTTPS 站点链接到对应 GitHub Release。核对版本、通道与 SHA-256；不要下载来历不明的重新打包版。关闭更新时可以手动下载。应用仅在您主动检查时联网，下载后验证更新签名；安装前结束导入（含暂停批次）、关闭导出预设并结束外部编辑出图，等待编辑保存和数据库迁移完成。下载失败可重新检查，安装失败使用同版或更高版本完整安装包恢复。

Windows 信任提示
有效发布者签名、SmartScreen 信誉与官网来源是不同层面的信任。未签名或信誉不足的程序可能受到提醒或拦截；请核对发布页说明，Smart App Control/公司策略下未必能继续运行。不要把关闭系统保护作为通用安装步骤。尚无 MSIX 商店版本时，不能把传统安装包称为“微软商店已认证”。

数据位置与卸载
相片与 catalog 在您选择的库内；设备设置、缓存与 app.db 位于应用的本地数据目录。卸载安装器只处理应用文件，不主动删除照片库。是否出现系统/商店卸载数据行为仍需对应安装形态实测。重新安装不等于数据库回退；更旧程序会拒绝打开更高版本库，请保留迁移前快照和独立备份。

求助与诊断
通过关于窗口的仓库链接提交 issue。先提供版本、Windows 版本、重现步骤和错误代码；可复制关于窗口的诊断摘要，它不含照片、目录、用户名或库记录。日志、截图、错误清单、原始照片可能含私人路径或 EXIF，分享前自行检查。没有后台遥测或自动上传诊断包。

支持开源
欢迎报告问题、提交改进和帮助其他使用者。捐赠账户尚未配置；应用不会提供未经确认的收款地址。
