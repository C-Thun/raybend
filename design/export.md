## 2. 外壳（三行，与 browse / editor 逐项对齐）

`titlebar` 36 / `flowbar` 48 / `toolsbar` 36（紧凑档；宽松档 44 / 62 / 44），配色与分区见 `DESIGN.md` §2。

- `flowbar` 的 `FlowSwitcher` 选中 **`导出`**；`ExifStrip` 与 import / browse / editor 共用同一份元数据源
  （品牌 + 机型 / 镜头 / 曝光 / 尺寸四组，均可 `easy copy`）；
  末端是**全屏看图按钮**（`IconButton` + `maximize`，命令 `viewer.fullscreen`，默认键 `F11`），跟随图片信息出现。
- 三行外壳与 `design/browse.md` §2.1 一致，**不重复叙述**。

### 2.1 `toolsbar` 的三段式（`prompts/exports.pd` 口述）

```text
mid：        [送入队列]  [取消选中]  [重置所有队列]        ← 整组按工具栏全宽居中
覆盖层： [展示范围]                                 [全部停止]
         └ left + 渐隐                         渐隐 + right ┘
```

| 段 | 装什么 | export 现状 |
| --- | --- | --- |
| **toolsbar left** | （通则：与**左列**相关的面板开关） | **`展示范围` 三态**：`全部` → `仅定稿` → `编辑过`，**反复点击循环**，持久化 |
| **toolsbar mid** | 该工作流的功能按钮 | `送入队列`（主色）/ `取消选中` / `重置所有队列`（两者次级色） |
| **toolsbar right** | （通则：与**右列**相关的面板开关） | **`全部停止`**：只有**至少一个预设处于导出中**时才可点 |

> ❗ 与 `AGENTS.md` §11.1 的通则有偏差：通则里 left / right 是「与左右两列相关的开关」，
> 而此处 left 装的是**控制中列显示范围**的筛选。**以 `prompts/exports.pd` 的口述为准**（人类原话优先），
> 通则可后续放宽为「与工作区相关的开关」。若人类认为该回退到通则，把三态换个位置即可。

**层叠与挤压**：mid 始终占工具栏全宽、不扣除 left/right；left/right 叠在其上，其不透明底覆盖重叠按钮，
内侧各加 20px 渐隐（与 `components/editor` 同一套做法，见 `design/editor.md` §2.1）。
画布上见 `Components / Export / ToolsBar 三段式与三态` 的「挤压 560」那条：mid 仍按整窗居中。

## 3. 左列：库与目录（**继承 browse，功能完全一样**）

- 三段：**搜索条 → 紧缩库列表 → 库内目录树**；宽度 **320**（紧凑档），**右边界可拖动**（220–520，人拖才落盘）。
- 库列表 ≤3 个库时只有缩起态；`查看所有库` 是第 4 位**伪卡片**（同宽同高同面，一行文案靠卡片顶部）。
- 目录树：选中行 `$state-selected` + 主色文件夹图标；行尾 `⋯` = 删除空目录 / 创建子目录。
  **点名字＝选中，点箭头＝展开**，两个动作分开；**不因为选中而强制展开树**（`DESIGN.md` §12.4.1）。
- 本稿逐项与 `design/browse.pen` 的左列一致（`design/browse.md` §2.2），export 不新增任何左列能力。

## 4. 中列：上下两个 tiles 窗口

中列宽 **920**，纵向 = **mid top 476（内容 444 + 完整 tiles statusbar 32）**
+ **三点分隔条 8** + **mid bottom 384（内容 352 + 精简 statusbar 32）** = 868。

### 4.1 高度与下限（人类要求「无级可拖 + 各有下限」）

```text
min(mid top) = 384   （内容 352 + statusbar 32）
min(mid bottom) = 384（同上）
两者之和 + 分隔条 8 = 776  ≤  工作区可用高 868   ← 还留 92px 机动
```

- **无级拖动**：分隔条是 `DESIGN.md` §12.5 的**三点细条**（8px 高，`row-resize` 光标、指向辅色底、拖拽中主色底），
  与 `film` 的胶片带分隔条**同一套**，不另造。
- **两个窗口都各自到底、各有自己的 statusbar**：不允许把某条 statusbar 提到两个窗口之间（跨窗口的横条＝违规）。
- 拖动时**不动 tile 尺寸**，只改可见行数；两个窗口的 tile 尺寸各自独立持久化（见 §4.4）。
- **上下限算法落到实现**：`min_top + min_bottom + handle ≤ workspace_h`，
  workspace 高度随窗口缩放变化 ⇒ 下限必须是**按当前工作区高度算出来并夹住**的（窗口特别矮时两个下限一起等比下调，
  不允许出现「拖到某一边时另一边的下限被顶破」）。

### 4.2 mid top —— 画廊：**按 issue 选**

- 能看到当前目录下的照片；**每张照片同时展开它的全部 issue**，显示哪部分由 `toolsbar left` 的三态控制：
  | 档位 | 显示 |
  | --- | --- |
  | `全部` | SOOC + latest（有编辑的）+ 命名定稿 |
  | `仅定稿` | 有手动命名定稿的照片；入选后完整提供所有定稿 |
  | `编辑过` | latest 与 SOOC/RAW 基准不同的照片；入选后完整提供所有定稿 |
- **网格单元 = 「照片 + 它的一行 issue 小片」**（画布上 172 宽）：
  - 上半是照片本体（tile 外形与 browse 相同：照片区 + 底部文件名条）；
  - 下半是 **issue 小片**（4:3 缩略 40×27 + 名字，画布一行最多 4 个），名字取 `SOOC` / `latest` / `v1` / 定稿名（如 `暖调`）。
- ❗**可选中单元是 issue 小片**（导出以 issue 为第一公民，`PLAN.md` M4-W2）：
  - 点小片 = 选/取消选该 issue（`$state-selected` 底 + 1px `$brand` 内描边）；
  - **点照片本体 = 整组全选**（该照片当前可见的 issue 全选，画布上 `P0002` 就是这个状态）。
- 选择模型（人类口述）：**默认就是 Ctrl 多选语义**，支持 Shift 区间；**按住 Ctrl 点击反而是单选**
  （会移除其它所有选中）——即「反 Ctrl」语义，实现时按这条接线，不要做成浏览器式 Ctrl 加选。
  ⚠️ 这就是**手势反转**（`invertedCtrl`）——它是**一等的、受支持的能力**（人类 2026-09-26：
  「正统支持」），**不是本工作区的临时特例**；完整口径（开关在数据源上、判定唯一一处、
  `Shift` 与同按退化两边一致）见 **`BROWSE.md` § 5.2.4**，术语见 `AGENTS.md` § 11.5。
- **按时间分组**（`DESIGN.md` §12.7）照旧生效，日组标题与片标题的「全选当天 / 全选此段」
  在这一层是**选中该范围内所有可见 issue**——并且与 `BROWSE.md` § 5.2.2 一样是**整段开关**
  （再点一次取消这一段）。
- 状态栏 = **与 browse 完全一样的完整 tiles statusbar**：`计数` — 弹性 — `当前目录 + 文件名` — 弹性 —
  `按时间` — `排序` — `缩放滑块` — 缩放图标 — `适合窗口`。

### 4.3 mid bottom —— 队列（**跟着导出预设走**）

- **每个导出预设一条独立队列**，互不干涉；换预设就换队列内容（状态栏中间的预设名条同时换）。
- **顺序**：新入队的照片放到**顶部**；导出**从下部开始往上**走 ⇒
  视觉上「底部＝已导出（最老）→ 中间＝正在导出 → 顶部＝刚入队/待导出」。
- **导完不删除**：已导出的留在队列里（**顶部右侧主色对勾徽标** + 信息条右侧 `已导出`），
  ① 告诉用户导过哪些 ② 防止重复导出；只有 `重置所有队列` 才清空（有确认）。
- 三种状态的样式（画布上都有）：
  | 状态 | 表现 |
  | --- | --- |
  | 待导出 | 普通 tile，信息条右侧显示格式（`ORF`） |
  | 正在导出 | 照片区 `$state-selected` 底 + **照片下缘 3px 进度条**（主色填充）+ 信息条右侧百分比（主色） |
  | 已导出 | 右上角 16px **主色圆形对勾徽标** + 信息条右侧 `已导出`（`$fg-3`） |
- 状态栏（**精简**）：`队列 N 张 · 已完成 M` — 弹性 — **预设名条**（圆角矩形 + 预设色点 + 预设名，
  回答「这条队列属于哪个预设」）— 弹性 — `列表模式` — `缩放滑块` + 缩放图标。
  **没有「按时间」，也没有排序**（人类口述「除了缩放外，只有列表模式」）。

> ✅ **已收口（2026-09-27）**：`列表模式` 是**开关**（保留），实现走**同一个 `PhotoGrid`、只换列数**
> （列表 = 单列，与 M4-W2 规格一致），队列区**不是**另写一套行式组件。
> 原❓的第二种读法（「队列只能是列表形态」）**不成立** —— 若人类原意其实是后者，说一声再改。

### 4.4 两个窗口的缩放独立持久化

- mid top 默认给一个**更大的** tile 档，mid bottom 默认**更小**；
- 两档分别持久化（设备级偏好，版本化 key + 一次性迁移，`AGENTS.md` §2.16），
  与 tiles/film 一样走 17 档等比阶梯（`DESIGN.md` §8 的 2026-09-23 口径）。

## 5. 右列：预设列表 + 参数表单

右列与各工作区共用 `--panel-w-right`（紧凑 276 / 宽松 288），纵向两段：上部列表弹性填满余高；下部设置按内容紧缩并沉底。

### 5.1 预设列表（上半）

- **卡片式**；列表占满上部剩余高度，只有预设装不下时滚动，不设固定最大高度；
- 卡片是**扁的**（58 高）：`图标块（28）` + `名称 / 关键参数一行` + 右侧**该预设自己的队列数**；
  关键参数一行 = `格式 · 质量 · 尺寸方式 · 目标目录`；
- **只有列表，不放任何操作按钮**。点选名称后整份参数载入下面；空列表提示 `当前无预设，请先新建`。
- 选中卡 = `$state-selected` 底 + 主色图标块（与库卡片同一套语汇）；
- **正在导出**的卡片与主按钮**同步打流光带**（人类要求：「该预设扁卡片也同样有此闪烁动画」）。

### 5.2 参数表单（下半）

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 名称 | 输入框 | 名称 trim/NFC 后与现有预设匹配 ⇒ 标题 `修改预设`、按钮 `变更`；不匹配 ⇒ 标题 `新建预设`、按钮 `新增` |
| 导出格式 | 四选一分段控件 | **WebP / AVIF / JPG / PNG**，按此顺序；TIFF 专供 browse 外部编辑（`IMAGING.md` §1.1） |
| 导出质量 | 拉杆 | 走 `DESIGN.md` §14.10 的拉杆样式（标签上行、值居右、两端极值槽位）；**PNG 隐藏本行，切回有损格式恢复质量值** |
| 导出尺寸 | 三行单选；数字框宽 96px（原 64px 加宽 50%），右侧固定单位 | 保持不变 / 百分比缩小（1–100%）/ 最大边长（1–65535 px），均只缩小 |
| 导出目录 | 输入框 + 打开文件夹按钮 | 记忆上次目录；**目录不存在/不可写时本行报错并禁用主按钮** |
| 导出文件已经存在 | 共享单行三选一 SegmentedControl | 覆盖 / 跳过 / 追加；默认追加，追加编号采用现有 `_01`、`_02` 递增规则 |
| 导出文件命名模版 | 输入框 + 变量提示 | **延用导入模版**（`REPOSITORY.md` §3.2 的 `:CYEAR :CMONTH :CDAY :CWEEK :FILENAME :SEQ000…`），`/` 创建子目录；重名按下述「导出文件已经存在」策略处理 |

- **实时校验**（人类要求「要实时检查一些数据，比如目录名是否存在，模版是否合法等」）：
  名称非空、目录存在且可写、模版合法（未知变量警告、非法字符报错、末尾 `/` 报错）——**全部通过才允许提交**。
- 名称是保存目标的唯一依据；与当前点选的预设身份无关。选旧预设后改成新名字会新增一个；改成另一个已有名字则变更那个同名预设。无需额外新建模式，也不自动保存。
- 底部固定同一行：紧凑的 `新增 / 变更` + 8px 间隔 + 撑满剩余宽度的 `开始导出 / 停止当前预设`。保存按钮放在滚动表单外，仍使用表单提交路径。
- 参数未保存时开始禁用，动作路径也校验；已开启预设的停止始终可用。按钮下保留一条提示：`设置修改后请先保存，再开始导出`。
- 预设文件导入/导出 **暂不启用**，无工作区、菜单或命令面板入口；仅保留底层文件能力。产品不提供目标路径/尺寸“导出预览”。

## 6. 状态、边界与禁用矩阵

| 情形 | 表现 | 依据 |
| --- | --- | --- |
| 未选任何定稿 | `送入队列` 禁用（**面退为中性格 + 前景 `$fg-3`**） | §2.8 给的是「面不变、前景降级」；**主色实底按钮不适用**（绿底 + 次级字看着仍可点），故退为中性格——**已在画布上按此画，待人类确认** |
| 没有任何预设处于导出中 | `全部停止` 禁用（`$surface-track` + `$fg-3`） | `prompts/exports.pd` |
| 至少一个预设导出中 | `全部停止` 可用（同形，前景 `$fg-2`） | 同上 |
| 队列为空 | mid bottom 显示**水印**：细笔画图标（64px / `stroke-width: 1` / `$fg-3`）+ 一句 `$fg-2` 说明，**无容器、无卡片** | `DESIGN.md` §12.10 |
| 无预设或未选预设 | 列表显示 `当前无预设，请先新建`（仅列表为空时）；下方仍可填写参数，标题按名称匹配显示；`开始导出` 禁用 | — |
| 导出目录不可写 | 目录输入行 **1px `$danger` 描边** + 红字原因；主按钮禁用 | 描边只给输入类控件（`DESIGN.md` §6） |
| 单张失败 | 不打断后续项；队列条目显示失败图标、原因与 `重试`，可选中/移除。没有独立失败清单、完成摘要或错误清单弹窗 | M4-W5 |
| 定稿哈希失效 | 自动跳过并从队列移除，计数/选择/去重同步更新，不保留失效条目 | M4-W5 |
| 重置所有队列 | 弹窗确认（说明「磁盘文件不受影响，只是丢失『导过了』的记录」）；确认按钮在右、用**主色**（不是危险色：它不动磁盘） | `AGENTS.md` §11.5、§11.3 |
| 成功 / 失败提示 | 右上角 toast，边框表状态（成功 `$brand` / 失败 `$danger`），底 `$surface-layer` | `DESIGN.md` §13.4 |

**动效口径**（流光带）：它是**状态指示类**动效，不是反馈类 ——
按 `DESIGN.md` §12.10 的两套时长纪律，用**秒级慢循环**（约 1.5–2s 一个来回、线性），

- 拖后保留原选择，可重复拖到其他预设；目标队列按库/相片/定稿哈希过滤重复，不显示虚假的新增计数。需要用户再次选点/全选/取消时恢复正常选择约束。
- 队列数字只有实际新增时动画；最多每秒 10 次。1 张只更新一次，小批可短于 1 秒，大批 1–3 秒且最多 30 次；按整数差值分配每次增量，最终精确到真实数量。执行导致待完成数变化时跟随真实状态，重置/删除/卸载取消旧动画。减少动态效果偏好直接显示最终值。
- Ctrl+A 沿用统一 `edit.selectAll`（Mod+A），作用于当前焦点 top 或 bottom；bottom 只全选 pending/failed，Delete 仅移除这些未执行项。拖拽是指针手势，不另增命令；键盘替代已有“送入队列”命令与 Enter。
