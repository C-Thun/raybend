## 2. 外壳（三行）

与 `design/main.md` §2 / `design/browse.md` §2.1 一致：`titlebar` 40 / `flowbar` 52 / `toolsbar` 40（紧凑档）。
`flowbar` 的 `FlowSwitcher` 选中 **`编辑`**（主色胶囊），`ExifStrip` 三组照旧。

### 2.1 `toolsbar` 的新形态 = **左 / 中 / 右三段**（`prompts/editor.pd` 口述，2026-09-23）

```text
┌───┬───────────────────────┬───┐
│左 │          中           │右 │      左/右靠边、中段居中；未指定的一律放中段
└───┴───────────────────────┴───┘
```

| 段 | 装什么 | editor 现状 |
| --- | --- | --- |
| **toolsbar left** | 与 workspace **左列**内容相关的面板开关 | **只有一个 `LUT`**（未来可有多个，逻辑按「一组互斥开关」实现） |
| **toolsbar center** | 具体功能按钮（与以往一致） | **裁切 / 旋转 / 对比** 三个工具 |
| **toolsbar right** | 与 workspace **右列**内容相关的开关 | **暂空**（占位保留；未来加东西才出现在这一侧） |

**挤压行为（人类明确）**：窗口变窄、中段按钮变长时，**中段被左右两段的底纹「盖住」** ——
用的是**渐变淡出**（左右段底纹向中间渐隐），**不是硬边 + 阴影**，也不是按钮互相叠错位。
画布上见 `Components / Editor / ToolsBar 三段式` 的「挤压 560」那条：最左边那个图标已经淡到看不清。

> 这条同时写进了 `AGENTS.md` §11.1 的术语表（`toolsbar left` / `toolsbar right` / 无前缀 = 中段）。

### 2.2 右栏 = **从上到下三个页签组**（人类 2026-09-23 纠正）

**不是**一条总页签 + 子页签，而是**三个各自独立、同时在场**的页签组，每组 = 页签条 + 内容区：

| 组 | 页签 | 内容 |
| --- | --- | --- |
| **第 1 组** | `总览` · `定稿` · `信息` | 总览 = 预览框（固定 4:3，`components/ui/PreviewFrame.tsx`）+ **缩放控制**（`− 100% ＋`，人类 2026-09-24 加）+ 直方图；定稿 = 该图的 issue 列表 + 「定稿为新 Issue」；信息 = **三组**（与调节相关：色温基线/当前色温/曝光补偿 → 拍摄：时间 → 文件：名/路径；与 flowbar 重复的字段**不出现**，人类 2026-09-24） |
| **第 2 组** | `影调` · `色彩` · `清晰度` · `镜头` | 影调：曝光/反差/高光/黑区/动态反差；色彩：色温/饱和度/自然饱和度（**只有拉杆，不放色轮**，人类 2026-09-23）；清晰度：杂点降噪/杂色降噪/锐化强度/锐化范围；镜头：配置文件 + 启用校正 + 畸变/暗角/色差 |

> **`动态反差` 已归位「影调」页签**（人类 2026-09-24 定「纳入与调曝光亮度曲线等一样的业务框架下」）：
> 它曾**暂时**挂在「总览」页的直方图下面（`placement: "overview"`）—— 归位时那个 `placement`
> 机制已**整个移除**（不再有「寄居在别处」的参数，`paramsInGroup()` 按组取就是全集）。
> 算法与参数口径见 `AGENTS.md` §11.5「动态反差」。
| **第 3 组** | `曲线` | 曲线编辑器（4×4 网格 + S 形曲线 + 控制点）+ 通道切换 R/G/B/RGB |

- **`AI调节` 暂不做**（人类：「AI 这块只是我写了一下现在不做」）—— 画布上**不出现**这一项。
- 页签条形态 = `$surface-track` 凹槽 + **选中项主色实色胶囊**（与 `SegmentedControl` 实现一致，
  `src/components/ui/SegmentedControl.tsx` 的 Indicator 就是 `bg-brand`）。
- **组与组之间只用间距（12）分隔，不加分隔线**（无边线设计）。

## 3. 各区域细节

### 3.1 workspace left —— LUT 面板（`prompts/editor.pd`）

- **占据整个 left、不可调宽**（没有拖拽把手），画布取 **280px**（紧凑档）。
- **默认打开**（人类 2026-09-23 定），且**开关状态要持久化**（设备级偏好：版本化 key + 一次性迁移，
  照 `AGENTS.md` §2.16 的口径，不要每次启动重置）。
- **一个 `LUT` 标题行**：进度为「新建分类」+「导入 LUT」两个图标按钮（都在行尾）。
- 下面是**一级分类**列表，每个分类一行标题（chevron + 名称 + 数量），点标题展开 / 收起；
  展开时**其他分类自动收起**；再点同一个标题可以全部收起。
- 展开后是 **一行 2 个 LUT tile**：上面是「当前照片 SOOC 缩略图经该 LUT 处理后的预览」，
  下面是 LUT 名。**已应用的那一张**用 1px 主色内描边 + 右上角主色对勾徽标表示。
- 点 LUT = 应用到当前照片（要等待，见 §3.5 的应用中弹窗）。

> **待补（人类已标注 TODO）**：tile 预览用的是「SOOC/issue 概念的缩略图策略」，
> 该策略还没定 —— 画布上先用平色 `$surface-bar` 占位。

### 3.2 workspace mid —— 视口 + 胶片带 + statusbar

- 中列结构与 browse 的 `view` / `film` **同一套**：`EditorViewport` → `FilmStrip Resize Handle / 三点` →
  `FilmStrip` → `PhotoStatusBar`（**每列各自到底，没有跨列行**，`AGENTS.md` §11.1）。
- 与 import / browse 的差别：**这里的 view 是 GPU 直绘的编辑视口**，且**没有 tiles 模式**
  （要回网格就去 browse flow）。
- `FilmStrip`：148 高、tile 158×132、选中项 `$state-selected` + 1px 主色内描边；装不下时从左排起。
- 画布上视口里的「照片」是**占位块**（`$surface-main` + 图标 + 说明），不是真实照片。

### 3.3 Tab 三档（editor 专属，与 browse 四档不同）

| 档 | 内容 |
| --- | --- |
| ①（默认） | `left + right + 胶片带 + view` |
| ② | 再按 Tab：**先藏胶片带** → `left + right + view` |
| ③ | 再按：**仅 view**（左右面板与胶片带全关） |

- **只在第 ③ 档动左右面板**：进入时若 LUT 面板开着就关掉（**临时记住**），离开 ③ 时恢复原状；
- ①② 档**不碰** LUT 的开/关状态；
- **任意档位下都允许用鼠标点 `toolsbar left` 把 LUT 面板开回来**。
- 示意帧：`States / Editor / Tab 三档`（三格示意，非像素稿）。

### 3.4 三个工具（`toolsbar center`，互斥，同一时刻只有一个控制块）

**共同线型**（人类指定）：**中间 2px 浅色线，两侧各 1px 深色线** —— 保证压在任意照片内容上都清楚。
画布上落在两个新变量 `$overlay-line`（浅）与 `$overlay-halo`（深）上（**两主题同一值**，
因为它们压在**照片**上、不压界面面；见 `DESIGN.md` §9.2 的新条目）。

| 工具 | 框线 | 把手 | 右栏控制块 | 退出方式 |
| --- | --- | --- | --- | --- |
| **裁切** | 4px「深-浅-深」线 + **井字主色线** | **四角 + 四边中点**都有加粗外框线 | 比例下拉（自由/原始比例/1:1/3:2/2:3/4:3/16:9/自定义…）+ 反转比例 + 取消比例限制 + 横/纵两个输入 + 取消/确认 | ① 控制块「取消」② 再点一次 toolsbar 上的裁切 ③ `Esc` |
| **旋转** | 同上但**井字线改用辅色**、**没有加粗把手**（一眼区分「这是旋转不是裁切」） | 无 | 角度拉杆（默认把手在正中，左逆右顺，最大 ±360）+ 重置 + 提示「在画面中拖一条水平线可自动摆正」+ 取消/确认 | 同上 |
| **对比** | 画面中间一条竖线（同样的「深-浅-深」），线纵向中间一个**双侧外粗线方框**作为把手 | 拖动把手左右移 | **无控制块** | 再点一次 toolsbar 上的对比 |

**几何边界（都不可越界）**：
- 裁切框最大只能在图像范围内（画布上画的是一张 3:2 照片里缩进后的框；真实默认是**撑满**）；
- **旋转之后再进裁切**（人类 2026-09-23 补）：打开裁切时显示的是**被旋转过的原图画布**
  （不是水平化之后的），裁切框**只能在“有像素”的范围内拖** —— 即边界是旋转后画布的边缘，
  而**不是**那个水平展示框。
  > 画布上 `States / Editor / 裁切` 画的是**未旋转**的简单情形（好读）；
  > 「旋转后再裁切」是同一个工具在另一个几何下的表现，本版没有单独画帧。
- 旋转时**展示框保持水平**、且随角度增大而**按原画幅比例缩小**，保证框内不出现空白 —
  **框就是成片边界**（画布上：斜着的画布铺满视口 → 水平内接框 → 框外压暗）。
  ⚠️ 这条 2026-09-23 被人类纠正过一次：**框不能小于画布**，
  早期的画法（斜照片浮在视口里、框再套在里面）是错的。

**对比的 statusbar**（人类指定）：左边显示 **`SOOC`（主色按钮状，点开可换其他 issue，
未来完善）**，右边显示**当前结果**。画布对比帧里这一条已经这么画了。

### 3.5 浮层（`Components / Editor / 浮层`）

| 浮层 | 用途 | 口径 |
| --- | --- | --- |
| `Modal / 导入 LUT` | 选 .cube 文件 → 选分类或新建分类 → 导入 | 中央模态；分类用 chip 行（当前分类 `$state-selected`） |
| `Modal / 应用中` | 点 LUT 后要等一会儿 | 进度条 + 取消；不阻塞其它窗口（真实实现待定） |
| `Popover / 裁切比例` | 比例下拉展开态 | 行 = 名称 + 当前项右侧对勾；指向态 = 辅色底（`$state-hover`） |

**按钮顺序（人类 2026-09-23 定，全系统适用）**：**取消一律在左，确认/前进类一律在右。**
已写进 `AGENTS.md` §11.5。

### 3.6 拉杆（右栏第 2 组）

样式规范在 `DESIGN.md` §14.10，要点：**标签在上行、小一号字、居左；当前值同行居右；
轨道等宽（两端为极值预留固定槽位）；极值可显示可不显示；双极/单极决定填充方向；
未填充段用 `--slider-track`（反色方向的中性色）。**

### 3.7 Ark UI 可行性复核（人类 2026-09-23 要求）

把画布上的控件逐个对到 Ark UI（`@ark-ui/solid`）的现成件上，标出“能直接用 / 要包一层 / 没有”：

| 画布上的控件 | Ark UI | 结论 |
| --- | --- | --- |
| 页签条（三组） | `Tabs` | ✅ 直接用；三组各自独立实例；选中块用 `Indicator` + `bg-brand` |
| 拉杆（含标签/值/极值/双极填充） | `Slider` | ✅ 用 `Slider` 做骨架；**外面包一层 `SliderRow`**（标签/值/极值槽位） |
| 工具开关（LUT / 裁切 / 旋转 / 对比） | 无 | ⚠️ 用 `Toggle`（Ark 的 `Toggle` 或普通 `button` + `aria-pressed`）—— 与现有 `ToggleBlock` 一致 |
| 裁切比例下拉 | `Select` / `Menu` | ✅ 用 `Select`（带 `Portal`）；比例项的勾选用 `Select.ItemIndicator` |
| 分类展开/收起（LUT） | `Collapsible` / `Accordion` | ✅ `Accordion`（单选展开 = `collapsible` + 同一时刻只开一项） |
| LUT 导入弹窗 / 应用中弹窗 | `Dialog` | ✅ 直接用（与现有建库/标签弹窗同一套） |
| 提示气泡（LUT 名过长） | `Tooltip` | ✅ |
| 镜头配置文件下拉 | `Select` | ✅ |
| 启用镜头校正开关 | `Switch` | ✅ |
| 曲线编辑器 | 无 | ⚠️ **自研**（SVG/canvas + 指针事件），Ark 无对应件；不要硬塞 `Slider` |
| 裁切/旋转/对比的视口交互 | 无 | ⚠️ **Rust 侧**：命中测试与拖动意图都发 IPC（`AGENTS.md` §6.1 红线 2） |
| issue 列表 | 无（纯列表） | ✅ 普通列表 + `Menu`（行尾 `⋯`） |
| 左右栏拖拽分隔 | `Splitter` | ✅（editor 左栏不可调宽，右栏固定 —— 本版没用到，留给 browse/import） |
| 胶片带 | 无（自研，已有） | ✅ 复用 `FilmStrip` |

**结论**：editor 没有需要新引入第三方件的控件；唯一的自研项是**曲线编辑器**与**视口交互**（后者本来就在 Rust 侧）。

### 3.8 空态四态（`States / Editor / 空态四态`）

`prompts/editor.pd` 要求处理四个边界：**没有库 / 库没有导入目录 / 目录里没有照片 / 有照片但未选中**。
四格都是**视口里的水印**：64px 细描边图标（`$fg-3`）+ 一句话 + 一行提示（`$fg-3`），
**不成卡、不加边框底色**（沿用 `DESIGN.md` §12.10 的网格水印口径）。
四格的 caption 里写明：**此时右栏控件应为禁用态**（画布上没画禁用态，见待决项）。

## 5. 命令注册表接入评估（`AGENTS.md` §2.15）

| 功能 | 是否进命令注册表 | 理由 |
| --- | --- | --- |
| 切换 LUT 面板 | ✅ 建议进 | 它等价于「显示/隐藏 LUT 面板」，适合 `view.toggleLut` 之类的命令 + 可绑键 |

## 8. 画布操作约束（本轮实测，接着 `browse.md` §4 补）

| 约束 | 说明 |
| --- | --- |
| **跨文件 `Copy` 不可用** | `Copy("PRpZa", …)` 在 `editor.pen` 里报 `Can't find node` —— **画布之间互不可见**，外壳只能在本文件重搭（结构可从 `browse.pen` 读出来照抄） |
| **`Get(id)` 拿到的是纯 schema 数据** | 可以直接 read → 手工改 → 重新 `Insert`，但**不能跨 execute 调用保存变量**（下面那条） |
| **变量不跨调用** | `myId = Insert(...)` 里的 `myId` **下一次 `execute` 就没了**（与官方 skill 描述不符），要么写死 id、要么重新按名字找 |
| **`Update(id,{fill:undefined})` 清不掉属性** | 要把「曾经的主色底」清成无底，得显式 `fill:"$surface-track"`（与凹槽同色 = 看上去没有底）。本轮踩过：页签改文案后旧的主色底留在别的项上 |
| **`TakeScreenshot` 不可靠** | 同一批改动里截图常常拿到**空白**；换到「只读 + 截图」的独立调用里稳定得多 |
| **`Export` 比截图可靠** | `Export([id],"png","/tmp/pen-shots")` 落盘后用图片查看器看，清晰度也更高（2x） |
| **渲染有高度上限** | 节点在 `y ≳ 1900` 之后截图/导出会**整块空白**（疑似渲染纹理高度限制）。画布已按此把帧排进 `y ∈ [0,1870]` |
| **图标库** | 画布只有 lucide / feather / Material Symbols / phosphor；**没有 Tabler**。实现用 Tabler，映射见 `design/browse.md` §3。LUT 用 `palette`（实现建议 `color-filter`） |
