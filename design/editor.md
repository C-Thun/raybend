## 2. 外壳（三行）

与 `design/main.md` §2 / `design/browse.md` §2.1 一致：画布硬写 `titlebar` 40 / `flowbar` 52 / `toolsbar` 40 —— **只是画布值**；实现以 `src/styles/tokens.css` 为准 = 紧凑 **36 / 48 / 36**、宽松 **44 / 62 / 44**（`DESIGN.md` § 8.4）。
`flowbar` 的 `FlowSwitcher` 选中 **`编辑`**（主色胶囊），`ExifStrip` 与 import/browse 共用当前选中文件的元数据源；品牌+机型一组、镜头独立一组，均可 EasyCopy。

### 2.1 `toolsbar` 的新形态 = **左 / 中 / 右三段**（`prompts/editor.pd` 口述，2026-09-23）

```text
mid：        [SOOC/RAW][撤销][重做][裁切][旋转][对比]     ← 整组以工具栏全宽居中
覆盖层： [LUT]                                      [重置修改]
         └ left + 渐隐                           渐隐 + right ┘
```

| 段 | 装什么 | editor 现状 |
| --- | --- | --- |
| **toolsbar left** | 与 workspace 左列对应的开关 | `LUT` |
| **toolsbar mid** | 整组操作按钮 | **SOOC/RAW → 撤销 → 重做 → 裁切 → 旋转 → 对比**；整组按工具栏全宽居中，不分子区域 |
| **toolsbar right** | 全局编辑动作 | **重置修改**；点击先确认，再清除当前照片的调整、曲线与镜头设置 |

**层叠与挤压**：mid 始终占工具栏全宽，不扣除 left/right；left/right 叠在 mid 之上，
其不透明底覆盖重叠按钮，内侧各加 20px 渐隐。渐隐属于覆盖层，不在 mid 内，也不放组件。
画布上见 `Components / Editor / ToolsBar 三段式` 的「挤压 560」那条：最左边那个图标已经淡到看不清。

> 这条同时写进了 `AGENTS.md` §11.1 的术语表（`toolsbar left` / `toolsbar right` / 无前缀 = 中段）。

### 2.2 右栏 = **从上到下三个页签组**（人类 2026-09-23 纠正）

**不是**一条总页签 + 子页签，而是**三个各自独立、同时在场**的页签组，每组 = 页签条 + 内容区：

| 组 | 页签 | 内容 |
| --- | --- | --- |
| **第 1 组** | `总览` · `定稿` · `信息` | 总览 = 全图预览框（比例随照片变化，限于 3:1～3:4，`components/ui/PreviewFrame.tsx`）+ **缩放控制**（`− 100% ＋`，位置暂时不动）+ 直方图；定稿 = 该图的 issue 列表 + 「定稿为新 Issue」；信息 = **原始拍摄数据完整列表**，按调节相关、拍摄、文件分组，最高 24rem，超出内部滚动，不显示当前调节值 |
| **第 2 组** | `影调` · `色彩` · `清晰度` · `镜头` | 影调：动态反差/曝光/反差/高光/黑区；色彩：色温/饱和度/自然饱和度（**只有拉杆，不放色轮**，人类 2026-09-23）；清晰度：同行「降噪方式」标题 + 紧凑二选一（快速/高质量），以及杂点降噪/杂色降噪/锐化强度/锐化范围；镜头：当前应用配置状态行 + 配置文件选择弹窗 + 启用校正；桶形/枕形校正、暗角补偿/范围、红/青边与蓝/黄边独立微调 |
| **第 3 组** | `曲线` | 曲线编辑器（4×4 网格 + S 形曲线 + 控制点）+ 通道切换 R/G/B/RGB |

> **`动态反差` 已归位「影调」页签**（人类 2026-09-24 定「纳入与调曝光亮度曲线等一样的业务框架下」）：
> 它曾**暂时**挂在「总览」页的直方图下面（`placement: "overview"`）—— 归位时那个 `placement`
> 机制已**整个移除**（不再有「寄居在别处」的参数，`paramsInGroup()` 按组取就是全集）。
> 算法与参数口径见 `AGENTS.md` §11.5「动态反差」。
> 2026-09-25 顺序调整：动态反差是影调的第一根拉杆；主稿与调整面板组件帧均按此顺序绘制。

- **总览图源**：与 browse 共用 `PreviewFrame`；只给完整的 Screen 图（最长边 ≤1920，不做 grid/strip 的 3:1 裁切）。
  外框占满右栏可用宽度；照片比例在 3:1～3:4 内时外框随比例变化，超出时框高停在边界，整图缩入并留白。
- **SOOC/RAW**：切换底图时，其它参数与曲线维持当前值；镜头配置及其启用开关在内存中按两侧分别保存。落为 latest 时只记录当前一侧为来源，预览/胶片带/网格据此生成。
- **命令**：SOOC 与 RAW 各有统一命令，和工具栏走同一选择动作；默认热键留空，避免输入参数时误切源。重置修改沿用既有命令，确认后才执行。
- **刷新节奏**：拉动拉杆期间仅视口跟手，总览、胶片带和直方图保持上一份；松开后生成 latest 的 preview/strip/tile，替换总览与胶片带时保留旧图直至新图可解码。直方图按当前 SOOC/RAW 与当前调节结果计算，同样在松手时更新。
- **缩放控制**：仍位于总览预览图下方；此次不调整位置。
- **紧凑选择**：直方图 RGB、曲线 RGB/R/G/B、降噪方式共用 `CompactChoice`，区别于右栏大页签。
- **曲线底纹**：每个通道显示对应直方图；RGB 通道显示由原图线性亮度计算的分布。
- **直方图空态**：同一个 `Histogram` 组件保持 176px 高度、网格与通道行；无数据时不画峰状图，在绘图区中央以次级文字显示「暂无数据」。设计稿 `States / Histogram / 暂无数据`。
- **重置**：四个参数面板末尾不放统一重置与说明；工具栏右端唯一入口弹确认框，曲线自身的通道重置保留。

- **`AI调节` 暂不做**（人类：「AI 这块只是我写了一下现在不做」）—— 画布上**不出现**这一项。
- 页签条形态 = `$surface-track` 凹槽 + **选中项主色实色胶囊**（与 `SegmentedControl` 实现一致，
  `src/components/ui/SegmentedControl.tsx` 的 Indicator 就是 `bg-brand`）。
- **组与组之间只用间距（12）分隔，不加分隔线**（无边线设计）。

### 3.1 workspace left —— LUT 面板（`prompts/editor.pd`）

- **占据整个 left、不可调宽**（没有拖拽把手），画布取 **280px**（紧凑档）。
- **默认打开**（人类 2026-09-23 定），且**开关状态要持久化**（设备级偏好：版本化 key + 一次性迁移，
  照 `AGENTS.md` §2.16 的口径，不要每次启动重置）。
- **一个 `LUT` 标题行**：进度为「新建分类」+「导入 LUT」两个图标按钮（都在行尾）。
- 下面是**一级分类**列表，每个分类一行标题（chevron + 名称 + 数量），点标题展开 / 收起；
  展开时**其他分类自动收起**；再点同一个标题可以全部收起。
- 展开后是 **一行 2 个 LUT tile**：上面是**该 LUT 的封面图**（口径见 §3.1.1），下面是 LUT 名。
  **已应用的那一张**用 1px 主色内描边 + 右上角主色对勾徽标表示。
- 标题下方有独立的 **应用 LUT** 开关；选中的 LUT 与开关一起写入 latest。关闭开关保留选择，重新开启即恢复。
- 点 LUT = 选择并立即应用到当前照片；封面本身不参与当前照片的实时计算。导入失败或应用内 LUT 文件丢失时，显示明确的不可用状态，不静默套用另一支 LUT。图库移除只隐藏条目，保留文件，已有编辑引用继续生效。
- tile 的封面固定 **4:3**，名称行显示导入文件名；同名文件导入后以内部唯一 ID 存储，不靠文件名定位。

#### 3.1.1 LUT 封面（效果图）—— 人类 2026-09-25 定

**封面在导入时烘焙并存储，读取有效缓存时不重新处理照片。**
编码版本升级或缓存丢失时，首次读取自动重建一次；伴生原图随 LUT 复制留存。
理由：tile 渲染零成本；LUT 原文件被移动 / 删除后封面仍然可显示。

> 这一条**取代**了原先设想的「用当前照片的 SOOC 缩略图实时套 LUT」。

**两种来源**（优先级自上而下）：

1. **LUT 自带的演示图** —— 导入目录里与 `.cube` **主文件名同名**的图片，
   按 `jpg` → `jpeg` → `png` → `tif` → `tiff` → `avif` → `webp` 的优先级取第一张。
   这类图是 **LUT 作者已经套好效果的展示图**，我们**只做几何处理，不再套 LUT**。
2. **回落：内置固定样片**（`lut-sample`）—— 没有自带图时，用固定图**套上该 LUT**再烘焙。
   固定图由人类提供，规格 **768×576（4:3）**。

**几何**：自带演示图按原图尺寸分两档，判据如下。
内置固定样片生成的效果封面固定 **384×288**：先在完整样片应用 LUT，再缩图。

| 原图条件 | 目标尺寸 |
| --- | --- |
| `w ≥ 768` 且 `h ≥ 576` | **768×576** |
| 否则（小图 / 竖图 / 超宽图） | **384×288** |

算法一律 **cover**：`scale = max(target_w / w, target_h / h)` → 按 `scale` 缩放 → **居中裁切**目标尺寸。

> **判据等价性**：`w ≥ 768 && h >= 576` 与「cover 缩放比 ≤ 1（不需要放大）」完全等价。
>
> **为什么是 cover 而不是「先缩到宽 768 再截中间 768×576」**：后者对 16:9 这类图不成立
> —— 1920×1080 缩到宽 768 只有 432 高，裁不出 576。cover 对 4:3 的原图与上述描述结果一致，
> 对其它比例也能给出正确结果。

**编码**：一律 **WebP 质量 80**（官方 libwebp 编码器）。下采样用 Lanczos3。
封面缓存版本与原图来源记录在 LUT 私有目录的 `cover-meta.json`；不是业务配置，不改 DB schema。
旧版本未记录来源且外部源目录已经丢失时保留旧封面，避免把作者自带的演示图替换为统一样片。

### 3.4 三个工具（`toolsbar center`，互斥，同一时刻只有一个控制块）

**共同线型**（人类指定）：**中间 2px 浅色线，两侧各 1px 深色线** —— 保证压在任意照片内容上都清楚。
画布上落在两个新变量 `$overlay-line`（浅）与 `$overlay-halo`（深）上（**两主题同一值**，
因为它们压在**照片**上、不压界面面；见 `DESIGN.md` §9.2 的新条目）。

| 工具 | 框线 | 把手 | 右栏控制块 | 退出方式 |
| --- | --- | --- | --- | --- |
| **裁切** | 4px「深-浅-深」线 + **井字主色线** | **四角 + 四边中点**都有加粗外框线 | 比例下拉（自由/原始比例/1:1/3:2/2:3/4:3/16:9/自定义…）+ 反转比例 + 取消比例限制 + 横/纵两个输入 + 取消/确认 | ① 控制块「取消」② 再点一次 toolsbar 上的裁切 ③ `Esc` |
| **旋转** | 同上但**井字线改用辅色**、**没有加粗把手**（一眼区分「这是旋转不是裁切」） | 无 | 角度拉杆（默认把手在正中，左逆右顺，最大 ±360）+ 重置 + 提示「在画面中拖一条水平线可自动摆正」+ 取消/确认 | 同上 |
| **对比** | 画面中间一条竖线（同样的「深-浅-深」），线纵向中间一个**双侧外粗线方框**作为把手 | 拖动把手左右移 | **无控制块** | 再点一次 toolsbar 上的对比 |

**几何边界（都不可越界）**：
- 裁切框最大只能在图像范围内（画布上画的是一张 3:2 照片里缩进后的框；真实默认是**撑满**）；
- **对比左侧来源**：状态栏同一个下拉中选择 SOOC、RAW 或本照片的命名定稿；定稿行显示名称和 RAW/SOOC 基准，选择后异步读取该定稿独立的 1920 预览。快速改选或换照片时只接受最新选择，旧预览不得覆盖；SOOC 不存在时标出实际的 RAW 参考帧。展开态见 `Components / Editor / 对比来源菜单`。
- **水平工具框坐标**：裁切框、旋转框、拉直线和对比分线由 Rust 用现有视口坐标计算，在照片的同一个 GPU render pass 中绘制；不再依赖 250ms 状态轮询绘制 DOM 线。未来图像像素锚定的 DOM 覆盖物仍复用 `ViewportOverlay` 的矩阵。前端不算视口变换。
- **旋转之后再进裁切**（人类 2026-09-23 补）：打开裁切时显示的是**被旋转过的原图画布**
  （不是水平化之后的），裁切框**只能在“有像素”的范围内拖** —— 即边界是旋转后画布的边缘，
  而**不是**那个水平展示框。
  > 画布上 `States / Editor / 裁切` 画的是**未旋转**的简单情形（好读）；
  > 「旋转后再裁切」是同一个工具在另一个几何下的表现，本版没有单独画帧。
- 旋转时**展示框保持水平**、且随角度增大而**按原画幅比例缩小**，保证框内不出现空白 —
  **框就是成片边界**（画布上：斜着的画布铺满视口 → 水平内接框 → 框外压暗）。
  ⚠️ 这条 2026-09-23 被人类纠正过一次：**框不能小于画布**，
  早期的画法（斜照片浮在视口里、框再套在里面）是错的。

**对比的 statusbar**（人类指定）：左边显示 **`SOOC`（主色按钮状，点开可换其他 issue，
未来完善）**，右边显示**当前结果**。画布对比帧里这一条已经这么画了。

## 8. 画布操作约束（本轮实测，接着 `browse.md` §4 补）

| 约束 | 说明 |
| --- | --- |
| **跨文件 `Copy` 不可用** | `Copy("PRpZa", …)` 在 `editor.pen` 里报 `Can't find node` —— **画布之间互不可见**，外壳只能在本文件重搭（结构可从 `browse.pen` 读出来照抄） |
| **`Get(id)` 拿到的是纯 schema 数据** | 可以直接 read → 手工改 → 重新 `Insert`，但**不能跨 execute 调用保存变量**（下面那条） |
| **变量不跨调用** | `myId = Insert(...)` 里的 `myId` **下一次 `execute` 就没了**（与官方 skill 描述不符），要么写死 id、要么重新按名字找 |
| **`Update(id,{fill:undefined})` 清不掉属性** | 要把「曾经的主色底」清成无底，得显式 `fill:"$surface-track"`（与凹槽同色 = 看上去没有底）。本轮踩过：页签改文案后旧的主色底留在别的项上 |
| **`TakeScreenshot` 不可靠** | 同一批改动里截图常常拿到**空白**；换到「只读 + 截图」的独立调用里稳定得多 |
| **`Export` 比截图可靠** | `Export([id],"png","/tmp/pen-shots")` 落盘后用图片查看器看，清晰度也更高（2x） |
| **渲染有高度上限** | 节点在 `y ≳ 1900` 之后截图/导出会**整块空白**（疑似渲染纹理高度限制）。画布已按此把帧排进 `y ∈ [0,1870]` |
| **图标库** | 画布只有 lucide / feather / Material Symbols / phosphor；**没有 Tabler**。实现用 Tabler，映射见 `design/browse.md` §3。LUT 用 `palette`（实现建议 `color-filter`） |

- 工具栏将已有「自动调整」按钮从右端移动到中段裁切按钮左边；仅当前资产同时有 RAW 与位图、当前基准为 RAW、照片未锁定且未在计算时可用。按下后显示计算中，完成后一次性更新基础曲线选择与影调、色彩、清晰度、镜头允许的参数。错误和未能拟合应说明原因，不改变已有选择。
- 「自动调整」继续使用现有 `editor.develop.autoAdjust` 命令，默认热键留空（避免误触）；基础曲线下拉属于局部选择，不新增命令。镜头弹窗保持已定的选择文案与按需推荐。

### 3.8 W6c：定稿、切换与缓存（2026-09-26）

- `design/editor.pen` 的右栏定稿列表包含 SOOC、RAW、最近编辑和用户定稿；SOOC/RAW 是固定源，最近编辑是自动保存的工作副本，用户定稿是不可变快照。定稿条目显示名称、RAW/SOOC 来源、时间与独立缩略图。
- 当前选中条目由**规范化配置哈希与完整配置比较**决定，不另外持久化选择 ID。匹配优先级为命名定稿 → SOOC/RAW 原始源 → latest；latest 是兜底。回到完全相同的配置时，原条目重新成为选中项。
- 工具栏右段“重置修改”右侧放“定稿”；只有配置与所有命名定稿及 SOOC/RAW 原始源均不相同时可点；与自动保存的 latest 一致不影响定稿。按下打开命名弹窗，默认名由影调与色彩形容词组合，再附两位起的 36 进制序号；可手改名称。同名在当前照片内逐次自增。保存后右栏滚回顶部并切到“定稿”。
- 点定稿条目把其完整 profile 载入编辑器并更新 latest。这一步作为一次撤销历史记录；撤销/重做恢复整套参数、曲线、LUT、源、镜头、基础曲线、几何与画面，控件和选中态同时刷新。修改过的定稿只可另存新定稿，旧条目可通过更多菜单删除，不提供覆盖。
- 每个用户定稿独立保留 384 长边网格图、192 长边胶片带图和 1920 长边预览图，均为 AVIF。导出时仍按 profile 实时计算。生成中显示占位；单张生成失败可重试，不能导致 profile 丢失。
- 定稿预览同时作为编辑对比工具的左侧来源；用户在状态栏的既有菜单中选 SOOC、RAW 或定稿，未为定稿另设一套切换控件。对比只读取快照，不改变当前编辑 profile、撤销历史或 latest。
- LUT 从图库移除时，条目隐藏且私有文件保留，已有 issue / latest 继续渲染；只有应用内文件实际丢失时才提示 LUT 缺失。引用与配置哈希仍保留，同内容重新导入可修复同一 ID 的文件。当前不提供自动清理或硬删除。


### 3.9 删除保护与 LUT 内容去重（2026-09-26）

- `Components / Editor / 删除保护`（`aPhpa`）展示定稿删除与 LUT 移除确认，沿用通用 ConfirmDialog。普通点击确认；Shift 点击跳过。确认框与按钮提示只说明操作对象及后果，不显示快捷操作教学文案；取消 / Esc / 遮罩取消不执行。
- 定稿删除清理其独立预览，当前 latest 保留；切照片或库时取消未确认请求。
- LUT 移除只隐藏条目，应用内 LUT、封面和原始导入文件都保留；已有照片 / 定稿的引用继续有效。
- 内容 SHA-256 在应用库中记录，同文件换名 / 跨分类导入仍去重。移除后重导恢复原条目与 ID；旧重复条目保持 ID，避免改变既有定稿。
- 导入结果在应用开关下方显示导入 / 恢复 / 重复跳过 / 失败数量（`LUT / 导入结果`，`pMsjq`）；仅展示本轮导入结果，不实时处理照片。

## 两层重置与基础曲线档案改名（2026-09-26）
