# browse 滚动、信息切换与预览读取修复

需求（2026-09-29）：browse tiles 在可滚动时点击多数 tile 会回到开头或向上跳；右栏在 tiles/film 切图时先卸载信息再填回；库内 tiles 应复用 latest preview，`+RAW` 只需目录配对，不应为显示格子反复读取 RAW。

## 实施边界

- 修复现有组件的状态生命周期，不改变布局、控件与既有 Pencil 设计。
- 虚拟列表仅在目录键真正改变时归零；点击保持滚动位置，键盘导航仍可滚入目标。
- 右栏保留上一份完整信息，当前照片的 EXIF 与定稿列表都结算后整体替换；清空选择/换库立即清空；迟到响应不得覆盖新选择。等待期间禁用旧信息的写操作。
- 库内 latest 小图优先复用已渲染的 preview，不重复显影；保留小图缓存、源版本校验及缓存缺失时的重建路径。目录实时扫描继续执行；未变化 RAW 不读内容，新增/变化文件仍需补录元数据。
- 既有浏览/选择操作修复，不新增命令或热键。

## 验收

- 自动回归：目录键不变时选择/分页不归零；键盘滚动正常。
- 单元测试：信息保持、失败、清空、换库与异步乱序；preview 命中不触发原片渲染，缺失可回退。
- 前端质量门、Rust 相关单测与编译、运行时冒烟。
- Windows 真实照片库的点击位置、右栏视觉与速度体感由崔总确认。
