1. 用 Pencil 修改画稿并同步设计说明。
2. `app.db` 新迁移：LUT 分类/条目与文件元数据；本体以唯一 ID 放应用数据目录。导入目录只扫三级，带图优先，否则内置样片套 LUT；支持 .cube 1D/3D/shaper 与 PNG/TIFF Hald。
3. `catalog.db` 新迁移：latest 的 LUT 选择+开关；不可变 issue 快照，schema version 与规范哈希；保留旧 latest 行并转换为工作副本，不丢任何历史编辑。缓存独立保存。
4. Rust 显影链复用一份 LUT 求值逻辑，编辑实时预览、缩略图、1920 预览走相同语义；缺失引用有明确降级。
5. 编辑器 UI：LUT 选择/开关/分类导入；右栏定稿列表与删除；工具栏定稿弹窗；切换/撤销/重做整体同步；状态栏既有对比来源菜单接入命名定稿的独立预览。所有新增动作评估统一命令与热键。
6. 单元测试覆盖解析/插值/边界、迁移、哈希与不可变约束、缺文件/删除引用、命名序号；通过前后端编译与单测，人工 Windows E2E 另行验收。

## 数据与兼容口径

- `latest` 是自动保存工作副本；现有三张 `develop_*` 表通过版本化迁移延续其数据，定稿另存完整 profile。
- 配置哈希由规范化后的 profile 计算，不把名称/创建时间/缓存路径算入。LUT 被禁用时，选中的 LUT ID 仍纳入配置哈希，保证开关和选择都能恢复。
- 删除用户定稿不删除 latest；缓存可重建，profile 不可损坏。
- 每个 issue 的 384/192 缩略图保存在 thumbs.db，1920 预览保存在库根 cache/full 下，缓存键包含 issue ID、profile 哈希和管线版本。
