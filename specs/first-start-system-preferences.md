# 首次启动的系统偏好

2026-09-29：首次安装建立 app.db 的同时，为尚未保存的设备偏好选择系统默认值。

## 行为

- 首次主界面渲染前读取系统应用外观：light / dark；无法检测时 dark。
- 系统首选显示语言为中文（含简体、繁体及 zh 的地区变体）时使用 zh-CN；其它语言或无法检测时 en-US。
- 已保存的主题、语言分别优先；缺失或非法的那一项才使用系统默认。启动后不持续跟随系统，手动切换仍通过原有命令。
- 密度仍为 compact。设置继续使用现有 localStorage 键，保留已有选择；不复制进 app.db。
- adapter 隔离平台：Windows 使用原生显示语言 API，Windows/macOS 外观复用 Tauri；Linux 外观与非 Windows 语言通过 WebView/browser 的媒体查询和首选语言补齐，为后续原生平台接入保留相同接口。
- 原生探测有 800ms 上限；失败、超时、存储不可用均不能阻断启动，迟到的响应不能更改界面。

## app.db 流程

复核 `setup → db::warm_up → DbState::get_or_open → AppDb::open`：创建数据目录和 backups，走现有迁移框架建立 app.db，再启动读池、写线程；由迁移闸门和 ui_ready 控制主窗口显示。系统偏好属于设备初始化，不改数据库 schema，不另建初始化通道。

## 验收

- [x] 空存储下系统 light/dark 正确；探测失败回落 dark。
- [x] 中文变体归中文；非中文、未知语言归英文。
- [x] 保存值优先，部分缺失按项初始化；后续启动保持选择。
- [x] adapter 的异常、无响应、非法载荷及存储禁用不影响启动。
- [x] TS/Rust 契约、前端质量门、数据库建立单元冒烟通过。
