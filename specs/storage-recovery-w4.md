# 可卸载存储 W4：副本选择与主动释放

执行已批准的 `design/main.pen` RQzd5 补充稿；四波一起交付真机验收。

多位置是同一库的可替代位置。多个登记路径指向同一个 catalog 实体（FileId 相同）可以视为别名；同时发现同 ID 不同实体的副本时，必须明确选择。选择操作在库设置的位置行，确认后固定实体身份，保存在 app.db 现有 settings（版本化 key）；选定实体不在时不得自动切到其它副本。导入、导出长任务有未完成项时不允许转写副本；先取消/移除原任务。选择需要重新核对 ID 与实体，串行退场旧连接后才能开新连接。

释放是主动停止使用：先设置每库屏障拒绝新任务与发布，取消该库导入，移除该库导出等待意图，等待正在运行的任务到安全点，退出 watcher、写者、读池，保留登记与文件。释放完成后状态为 released；自动观察、进入目录、后台探测都不能重新连接。明确点击重新连接才解除屏障。屏障为本次应用会话状态，重启按正常连接规则。释放期间显示 releasing，以中性文字告知等待；不承诺替操作系统弹出设备或关闭应用外部句柄。

采用现有 CatalogSessions、CatalogDb、ImportBatches、export Engine；不引入第二套生命周期或数据库迁移。借用短数据库操作由原读池/写者退场机制排干，长任务使用同一会话协调器的活动许可。非本库工作继续。

命令：`repository.release` 注册命令面板、文件菜单，不设默认键（低频且需确认，避免误触）；重新连接沿用 `repository.reconnect`，无默认键；位置行明确选择属于带位置参数的上下文操作，不新增全局命令。
