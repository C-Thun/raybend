# M3-W7：M3 收口

## 目标

在 W6 完成后核对 M3 的性能、图像证据、数据与文档，给出可交由人类在 Windows 真机验收的版本。W7 不新增编辑功能。

## 实施顺序

1. 核对 W6 数据路径：LUT、issue、latest、撤销/重做、独立缩略图与 1920 预览、缺文件降级。修复明确缺陷。
2. 运行已有离屏像素探针与合成图显影性能探针，记录预览档、24MP 档耗时和进程峰值内存；记录前端构建时长与产物体积、Windows debug 包体。交互帧率由 Windows 真机采样，人类裁决。
3. 同步 `AGENTS.md`、`DESIGN.md`、`BROWSE.md`、`FUTURE.md`、`IMAGING.md`、`PLAN.md`，明确 XMP 中 issue 的版本化表达契约。
4. 执行前端门禁、Rust 单测/编译、迁移冒烟和 Windows 构建检查。逐条核对 M3 DoD；不能由 Agent 验证的真实照片颜色、体感、DPI、原文件哈希留给人类真机。

## 验收边界

Agent 只报告可复现的数字和离屏像素断言，不以 WSL 合成负载推断 Windows 交互帧率。M3 源码/编译与文档收口后，真机视觉和真实照片库结论由人类验收。

## 已测基线（2026-09-26，WSL 合成数据）

- `target/debug/examples/develop-probe` 直跑，22 个可用并行线程：1920×1080 默认 7.8 ms、曝光 7.7 ms、带色度 13.1 ms、全部阶段 41.4 ms；6000×4000（24MP）默认 75.5 ms、带色度 114.2 ms、全部阶段 454.0 ms。独立进程峰值 RSS 657444 KB，整个探针同时持有预览与全尺寸合成图，不能当作应用单张照片内存。
- `pnpm debug:win`：前端热构建 651 ms；Windows debug 主程序构建 1m57s，完整脚本 130.76s；`dist/` 6.5 MiB，debug EXE 51,730,944 字节，RAW worker 13,622,784 字节。两者均是 debug 产物，不推断正式安装包体积。发布物由人类生成。
- `editor-offscreen` 的 Fit、洞口裁切、1:1、逻辑尺寸与纹理尺寸断言通过，PNG 位于 `/tmp/raybend-m3-w7-offscreen/`。
- 最终 W6c 对比来源补齐后，前端 954 项、Rust 核心 1084 项、桌面命令 85 项单测通过；`pnpm smoke:ui` 无问题；Windows debug 主程序与 RAW worker 重新构建，`check:win` 核对 4 个嵌入资源和协议通过。Windows cargo 最终重建 1m26s。

## Windows 真机验收（人类）

在 100% 与 150% DPI 各走一轮，使用真实照片库中至少一对 RAW+JPG 和一张单 RAW / 单 JPG：

1. 记录原文件 SHA-256；编辑曝光、色温、曲线、基础曲线、降噪、锐化、镜头、裁切与 LUT，退出重进后核对画面、配置和原文件 SHA-256 不变。
2. 导入 `C:\src\resource` 里的 CUBE，确认 4:3 封面、同名文件无碰撞、应用开关与已选 LUT 恢复；把源目录移走，已导入 LUT 仍能用；临时移走应用数据里的 LUT 本体时出现缺失提示且 issue 配置不丢。
3. 在同一照片上定两份不同的 RAW/SOOC issue，核对名称建议、基准标签、两档缩略图和 1920 预览；切稿、撤销、重做、删除后，图像与右栏选中态同步。浏览看图侧同样切换，缩略图跟随。进入对比工具，在状态栏依次选 SOOC、RAW、两份定稿，快速切换来源及照片，确认左侧只显示最新选择，当前编辑与撤销历史不变。
4. 在 24MP 以上真实照片上连续拖动曝光/色彩拉杆、滚轮缩放、适合窗口与 1:1 切换，观察是否跟手、是否跳帧；记录 5 秒交互区间的帧率与进程内存，重复 10 轮并核对没有持续上涨。Agent 的 WSL 合成耗时不能代替这一项。
5. 启动/接入旧 catalog 时检查迁移门、快照与编辑结果；人类在 Windows 上确认真实目录、DPI、颜色和镜头选择弹窗。这些属于 E2E，Agent 不声称已验证。
