# M3-W5　裁切、旋转、对比视口交互

> Agent 实施与冒烟验证：2026-09-25；真机 GUI/E2E 待人类确认。范围依据 `memory/FINISHED.md` §6（M3-W5）、`design/editor.md` §3.4，以及 W3 的视口覆盖层和 W4 的参考帧。当前 W3/W4 改动仍在工作区，实施时保留这些改动。

## 结束时可看到

- 三工具互斥。裁切框有八个把手、井字线和框外遮罩；比例预设及自定义输入真正约束拖动。旋转的水平内接框与拉线校正可用。取消与确认分别回滚和保存，无损编辑在重新打开、缩略图与看图中一致。
- 对比在同一照片几何中显示 SOOC/RAW 参考帧和当前结果，分线可拖动；状态栏标出两侧。
- 指针事件只传 CSS 窗口坐标和意图。命中测试、拖动、旋转后边界、裁切与对比切分均在 Rust；覆盖线共用现有视口矩阵。

## 实施顺序

1. 在 `render/viewport.rs` 建裁切、旋转内接框、把手命中和对比分线的纯几何模型及边界单测。旋转后的裁切框四角必须落在原图的旋转后像素域内。
2. 扩展单一编辑视口 IPC：进入工具、按下/移动/松开、比例/角度/确认/取消；渲染线程持有草稿，状态快照回传框、把手和分线。以请求顺序处理高频指针意图，尾样本必须送达。
3. 在现有 `ViewportOverlay` 画三种覆盖线，沿用 `--overlay-line`/`--overlay-halo`、同一矩阵与现成右栏控制块；工具按钮、Esc 和照片切换收口草稿生命周期。
4. GPU 使用 W4 已上传的参考帧画对分区域。裁切与旋转确认后写入现有编辑栈的新增几何字段；schema 只通过 `store/migration.rs` 升版本。缩略图、preview 与查看器复用同一 Rust 几何与像素处理入口；更新缓存签名/版本及撤销重做。
5. 接入现有工具命令并复核默认热键、双语言文案、设计说明和契约。运行前端门禁、Rust 单元/检查与离屏 GPU 冒烟，记录真机 GUI/E2E 尚需确认的项目。

## 边界

- 不改照片原文件；仅保存编辑栈。SOOC 与 RAW 参考帧沿用 W4 定义，其他 issue 交给 W6。
- 视口状态仍由 Rust 独有；前端覆盖层只画 Rust 返回的图像像素坐标。
- GUI 视觉、真实相片、DPI/跨屏和色彩正确性由崔总在真机 E2E 确认。

## 2026-10-08 修订：参照帧的口径与手势（崔总口述）

- **不同裁切 / 不同像素尺寸也能对比**（原「同一照片几何」的口径在参照比例不同时会硬拉伸）：
  左边那半永远是「参照帧**等比 cover** 填进当前画面」—— `s = max(cur.w/ref.w, cur.h/ref.h)`，
  两轴都不小于当前画面，多出来的部分裁掉（居中），比例不变、不留空。
  参照与当前画面比例相同时（SOOC 路径：参照按当前几何裁过）`s` 恰好等于旧口径（实测差 ≤ 1 ULP / 亚像素级）——不是新特效，是补上遗漏的那一路。
- 实现：参照帧有**自己的 uniform**（`Viewport::matrix_for(cover_size)`，与主图同布局不同内容）
  与**自己的 scissor**（洞口左半 ∩ `Viewport::image_rect()`，即**以当前画面为蒙版**，
  cover 后多出来的部分不溢到画面外的留白区）。选中的命名定稿仍读它自己的 1920 快照，缓存策略不变。
- **对比态也能拖图**：起手命中分线把手 ⇒ 拖分线（原行为）；否则 ⇒ 平移图像
  （`CompareGesture`，3 CSS px 阈值、松手补尾样本，与普通拖动同一手感）。
- 回归靶子：`render::viewport` 的 cover/scissor 单测 + 离屏像素冒烟
  （后者抓到过齐次矩阵 `w` 写错——四边形的 w=0 会被整块裁掉，纯几何单测看不出来）。
  实施记录：`implementations/2026-10-08_editor-compare-cover-and-panel.md`。
