# M3-W6b　显式自动调整与机型曲线学习

> 按 2026-09-26 人类方案实施；在 W6a 的可选基础曲线上继续，不进入 W6c LUT/issue。

## 交付

1. 复用既有「自动调整」命令，工具栏入口移到裁切左侧。仅 RAW、有配对位图、有品牌和型号、照片可编辑时启用，载入新图不自动拟合。
2. 点击后用 RAW 线性解码与直出位图的缩略级亮度分位数拟合单调曲线；以固定采样曲线值和局部斜率比较同机型档案。阈值内沿用原档案，超过阈值创建新档案。
3. 从直出分布生成保守曝光、反差、饱和度建议；调用现有镜头匹配选择候选。一次提交基础曲线和现有面板参数，不改用户曲线和其他功能。
4. 测试空/低反差输入、风格分离、参数边界与命令门控；完成前端和 Rust 编译冒烟。真实照片性能与观感交人类 E2E。

## 算法限制

亮度直方图只表达整体调性，不表达局部色彩风格；初始阈值需用真实跨场景样本标定。重复点击可能重复计入匹配次数，后续可按照片身份去重。
