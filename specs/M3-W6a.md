# M3-W6a　可选基础曲线与机型档案

> 按 2026-09-26 人类方案实施；工作边界见 `PLAN.md` M3-W6a。与 W6c LUT/issue 独立。

## 交付

1. 在现有 Rust 单调曲线管线增加一层 RAW 基础曲线，位于显示编码之后和用户曲线之前；SOOC 编辑不应用。没有选择时为恒等映射。
2. 机型档案只按 EXIF 品牌与型号索引，可容纳多个拟合档案；照片编辑栈保存所选档案与曲线快照，迁移旧栈到「不使用基础曲线」。
3. 曲线画布增加只读基础曲线叠线和下方档案选择；无机型信息时隐藏、SOOC 编辑时关闭。
4. 复用现有显影、缩略图、撤销和命令体系。用单元测试覆盖迁移、曲线顺序与 RAW/SOOC 切换。

## 边界

不做品牌或通用保底曲线、不按 ISO 分档、不改用户曲线控制点。真实 Windows GUI 与色彩效果由人类确认。
