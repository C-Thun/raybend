# 相片整理 AI-W2：标签来源、屏蔽和统一读取

> 2026-10-04 数据接缝已实施并通过Agent单元/编译冒烟；生产模型定版仍受 AI-W1 校准与 Windows 实测约束。崔总同意先用公开样本冒烟，真实照片库效果留真机验收。

有效照片标签唯一口径 `(manual ∪ valid_ai) − masks`。目录标签不继承。保留旧数字 ID 的手动写入口和撤销语义；数字关联是兼容适配，AI 不写成 manual。SQL view 统一文字导航、数字筛选、自动桶与导出读取。旧词典尚未对齐的数字关联仍可读，不静默丢失。

新增 catalog 正式迁移：文字屏蔽、成功结果/原始来源身份、提交 attempt 守卫。空结果也是成功；无效分数/过期 attempt/UID 被复用不能落库。失败/取消保留上次有效成功；原始源失效移出有效集合。人工保留只增加 manual 并解除同文字屏蔽；屏蔽/解除独立，事件走既有归集器。

XMP 在同一单元对齐：标准 keywords 只写有效文字；rb 版本化 JSON 保存来源/屏蔽及最小识别身份，导入自家扩展时不将 dc:subject 的 AI 再抄成 manual。旧 sidecar 无扩展仍按原规则采纳；新扩展未知版本/非法数据保护盘上文件。恢复 AI 标记 sidecar 来源，不伪装本地推理。复用现有 sidecar 队列，不创建第二写出器。

此单元的数据能力已供W3获批界面复用。命令与热键跟随获准的界面实施：默认热键留空（低频、范围需明确）。来源详情 IPC 供下一单元适配现有 TagDialog，单张草稿编辑/批量只加保持原约定。
