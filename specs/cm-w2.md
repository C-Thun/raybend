# CM-W2：输入配置、线性工作域与正确输出

> 2026-10-04 技术闭环已接通，默认激活受 W3 性能闸门约束；真实 RAW/照片色彩待统一验收。契约见 `color-management.md`，证据见 `../implementations/2026-10-04_color-management-float-gpu-and-persistence.md`。

## 已实现范围

Little CMS 静态链接校验 RGB ICC v2/v4（16 MiB 上限、设备类别、签名、通道、损坏拒绝）。原始字节 SHA-256 是身份；内置三份配置固定保存，生成时间不能改变指纹。矩阵/TRC 快路径对照 LCMS 样本网格；独立手工构造的 v2/v4 LUT8/LUT16/mAB CLUT 输入使用 LCMS，不能冒充 GPU 矩阵能力。

位图读取内嵌 ICC、标准标记及冲突，RGB8/16、灰度与 RGB32F 保留输入精度；非有限值拒绝。RAW 独立 worker 协议 v7 回传 f32、编码与相机矩阵身份；旧协议拒绝。当前标度由 adapter 进行不夹负值的黑/白电平归一化，再复用上游去马赛克与校准；固化旧矩阵身份仍重放原 Rescale，未知身份拒绝。预检身份通过隔离 worker 的 dummy metadata 请求取得，不再完整显影后丢弃像素。含 alpha 的完整编辑暂明确拒绝，避免静默丢透明度。

V2 使用 f32 线性 Rec.2020 D65，保留负值和 >1。调整算子复用现有实现，经不截断的线性 sRGB 桥接，尚不是全部原生 Rec.2020 算法。高质量降噪复用同一个可取消后台实现，缓存按源/镜头/降噪参数失效，全局参数变化复用结果。直方图读取有界参考样本，不受显示配置影响。

编辑器、缩略图、1920 代理、导出和外部编辑 TIFF 读取同一固化输入与处理版本。照片显式应用输入才进入 V2；旧照片、旧命名 issue 不自动改版。导出预设 v4 接上 sRGB/P3/Adobe/自定义 RGB ICC，缺失引用拒绝。JPEG、PNG16、TIFF、WebP 写实际目标 ICC，非 sRGB EXIF 标 Uncalibrated；AVIF 非 sRGB 仍禁用。

AVIF 代理通过共享 ISO BMFF 容器 adapter 增加 sRGB `colr/prof` 属性与关联，并修正绝对偏移；不改变 AV1 数据、不重编码。独立 AVIF 解码路径确认 ICC 和像素，附加 XMP 后仍一致。缓存管线版本 v15。此前改编码内部模型的 nclx 方案增加约 13% 时间/17% 体积，已舍弃。

## 性能边界

解析、输入 ICC 转换只在载入/源变化时发生；滑杆/平移/呈现不跑整图 LCMS。常见矩阵/TRC 2MP CPU 输入约 19ms，输出约 50ms（早期同机基准）；复杂 CLUT 复用有界 LCMS transform，最多四路像素分块，等候大图任务在分配输出前取得许可；RGB8 不再扩成整图 RGB16。O2/WSL 的真实 Panasonic DMC-G1 2MP 输入在同进程对照由 415.72ms 降至 143.18ms，输出逐 f32 相等（非每帧成本）。CPU 全局调整约 26–31ms 对旧路径约 12–13ms，实时全局调整使用 W3 GPU 小表；空间算子/离线输出保留共用 CPU 实现。高分辨率共享源与分块 half 上传的实测、Windows/WSL 边界见 `cm-w3-hardening.md` 和核心攻关实施记录，不以转 8-bit/提前 clamp 绕过。
