# CM-W4：色彩配置资产、照片级选择与复用

> 2026-10-04 首版应用路径已接通；设计在 main/editor/export.pen 及同名说明，用户授权自行设计后实施，手动保存由用户完成。

## 实现

ICC 与 LUT 导入共用受限文件快照/哈希底座，16 MiB 上限；配置字节复制到应用目录，app.db 迁移 10 登记。批量导入 256 文件上限，内容去重、隐藏/恢复、缺失反馈；隐藏不删除已引用资产，移动原文件不破坏引用。三份内置配置固定字节/指纹。

全局设置从菜单、命令面板、Mod+,、flowbar 无边框齿轮共用入口；同一 ProfileSelect 和组件令牌。默认输入/输出存 color.defaults.v1，内嵌/标准标记优先，默认变更不回写旧照片；窗口打开重读真实资源，保存有草稿/错误状态。flowbar 齿轮与全屏图标均跟随 flow 图标尺寸，指向辅色、设置打开主色。

editor 第三组为曲线/预设/色彩管理，输入选择先是草稿，后台核验源文件、ICC、RGB/RAW 与透明度后才提交；可恢复自动。切 RAW/SOOC 用实际源重做解释。同一编辑提交/撤销/派生失效；取消输入变更恢复旧处理版本，不让初始空载荷或跨照片迟到请求覆盖已保存 V2。

批量照片指定/恢复自动最多 256 张：先固定选择和目标、逐张预检，确认窗显示可应用/已有覆盖/跳过理由；提交再次核对文件、编辑栈、锁定、当前库，整批同一事务/撤销，失败不能先改其中一张。命名 issue 不改，latest 代理失效，XMP 走既有同步队列。

编辑预设新增默认不选的色彩管理组；只有 V2 可以保存，记录自动或指定输入指纹/处理版本，不复制某原片的内嵌数据。预设应用先完整预检再改其它组，失败不会半应用。输出目标归导出预设 v4。XMP rb canonical schema 1/2 保留固化输入/版本/指纹，旧 schema 和旧 hash 不变，缺失引用不能伪造精确导出。

## 命令与边界

打开色彩页、恢复自动、批量恢复自动、打样和色域警告登记统一命令；低频专业动作 defaultKey 明确留空，设置沿用 Mod+,。选择器、保存动作属于已有面板上下文，不另占默认键。显示/打样/设备默认不进入照片便携载荷。

RAW 相机矩阵可用；任意 RGB ICC 不能套 RAW。DCP/自定义相机风格、每机型默认覆盖尚非首版功能，见 FUTURE C1。
