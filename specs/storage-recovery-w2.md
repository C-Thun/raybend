# 可卸载存储 W2：导入源恢复一致性

崔总已授权连续完成 W2–W4，四波统一真机验收。本单元复用 W1 应用级卷观察器；不新增轮询、框架、schema 或界面控件，沿用已定的来源树、最近、已选目录和图片区。

卷变化与重新进入导入工作流重查最近、勾选和当前目录。最近加载完成后再核对路径，避免启动时空列表竞态。路径键统一复用 pathKey，短结果不得当成在线；探测单飞并补读期间的新请求。勾选计数以请求代次和递归选项校验，旧计数不得覆盖新操作。

展开树只重读已展开层，每次最多 4 个目录在途；同路径并发合并，恢复会作废旧代次并补一次新读取。照片区同路径恢复重新扫描，离线使旧异步结果失效，保留已显示照片、锚点和选择；排除与勾选保留。现有手动重试不变，恢复属于内部自动动作，不新增全局命令/默认热键。

验收：

- [x] 启动时最近列表晚返回仍会探测，空/中文/NFC/大小写/分隔符路径按统一规则比较。
- [x] 卷拔插同步可用状态、勾选统计、展开树与当前照片区，同路径恢复重读。
- [x] 探测、目录读取和计数的迟到结果不能覆盖新代次；高频通知有界合并。
- [x] 选择、勾选、排除与展开意图保留，不以后台恢复强制展开。
- [x] 前端单测、质量门与可重复合成冒烟通过；真实拔插统一最后验收。
