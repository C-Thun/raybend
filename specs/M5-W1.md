## 实现契约

1. release 计划保持纯函数：严格 SemVer、溢出/Windows 版本限制、两个 channel 参数形式、未知/重复参数拒绝；test 禁止升版，稳定/预览通道明确。
2. package.json 为产品版本来源，Tauri 读取该文件；Cargo workspace 与两条本地 Cargo.lock 包版本事务同步。正式包 git 状态获取失败、无 hash、脏树须明确阻断；允许脏树只用于显式接受。失败只恢复本次写入且不覆盖期间的外部修改。
3. 前端 test 使用独立 dist/test-build，正式与 beta 使用 dist；构建身份由 release 一次产生并传递，Windows 阶段不重建前端。发布 manifest 包含版本、通道、commit、时间、worker 协议与资源摘要。
4. 为崔总提供可执行 Windows release + bundle 命令：复用 dav1d，目标落 C:，--locked/custom-protocol，复用 check:win；签名和 updater 条件不足时清楚拒绝；有/无发布者签名由显式选项选择。只运行 dry-run 和合成工装，不生成正式包。
5. NSIS 每用户安装、双语、稳定安装身份；MSI 保留。安装资源包含许可/声明与源码取得说明；不添加卸载删除用户目录钩子。发布诊断页仅 dev/test，Rust spike 命令拒绝发行通道。
6. 首启用现有创建/打开入口，欢迎/隐私说明不造第二个库流程；Pencil 修改在现有 main.pen 中，配 main.md。新增可触发功能统一命令接入并当次决定热键。
