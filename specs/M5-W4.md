# M5-W4：签名与分发准备
开工：2026-09-26；仅推进脚本/说明/合成回归，实际发行由您执行。

复用已有 release/Windows 环境。准备 signtool 证书存储签名+HTTPS 时间戳、签名验证、SHA-256/字节清单和 Tauri 最新/预览 JSON；NSIS/MSI 目标分开，不让 MSI 安装跨到 NSIS。无签名分发必须由 --unsigned/--allow-unsigned 明确选择，并标注公开信任不等于更新公钥校验。签名服务/证书缺失不能冒充已签，更新 .sig 缺失不得生成更新清单。

身份/账户、SignPath Foundation 审核、商店应用身份与 MSIX 包装路径属尚缺外部输入；准备文档，不伪造 Publisher/商店应用 ID 或 Store 认证。不购买 EV，不承诺签名后立即无 SmartScreen 提示。MSIX 更新归商店，源码应可以编译为 store 分发并关闭内置 updater；用户数据位置/worker 自重启/外部编辑联动待实包验证。
