# Shift 区间语义修正 + 按时间分组的排版层次

完成时间：2026-09-16 15:49:05 CST

## 一、Shift 区间：我实现成了「替换」，规范里写的是「翻转」

人类原话：*「按住 shift 点击一次选择一批连续图片后……再次点击下一张图片，
反转这两个点之间的图片选择状态也没错，但为什么要把之前选中的取消？
不在反转范围内的选择状态，原来是什么现在还是什么，不改。」*

`BROWSE.md` §5.2 **早就逐字写死了严格语义**（「用户逐字描述，必须照做」），当时的实现是错的：

| | 规范 | 旧实现（错） |
| --- | --- | --- |
| 区间范围 | **不含**上一次的图，**含**这次点的图 | 含两端 |
| 区间内 | **逐项翻转** | 一律置为选中 |
| 区间外 | **原样不动** | **被清空**（`new Set(slice)` 新建集合） |

修法（`src/lib/selection.ts` 的 `range` 分支）：在原集合上**逐项翻转** `(anchor, target]`，
区间外一个都不碰 —— 也**不保存「上一次的区间」**（人类要求「无需保存复杂状态」）。
测试补了 `BROWSE.md` 的 **ABCDE 走查**（四步逐步断言），另加「区间外不动」与「反向」两条。

## 二、按时间分组：过于紧凑，缺大小标题与留白

人类原话：*「这部分本来就没有划线也没有色块分隔，全靠排版留白，现在这样叫人怎么区分？……
这个总要有明确的大小标题，加留白做区分。」*

`DESIGN.md` §12.7 只说「日组标题 / 片标题（小字）/ 缩略图行」，
实现里两级的差别只有字号 14→13 与行高 34→26，且**都居中** —— 看起来就是两行小字。

修法（照设计稿 `DayHeader` / `SliceRow` 的数值）：

* 标题行高改为 **`内容 + 上方留白`**：日组 `26 + 20 = 46`、时间片 `22 + 10 = 32`；
  留白**只加在上面**，标题就贴着自己那一组、与上一组拉开；
* 日标题：**14px semibold + `fg-1` + 日历图标**（一级标题）；时间片：13px `fg-2`（二级标题）；
* 「全选当天 / 全选此段」给药丸底（`state-selected` 高 20 / `state-hover` 高 18 —— 设计稿数值）；
* **单一事实源**：`rows.ts` 导出 `DAY_HEADER = { rowHeight, contentHeight }`，
  渲染方从同一对象推导留白（`rowHeight - contentHeight`），不另写一套 `pt-*`。
