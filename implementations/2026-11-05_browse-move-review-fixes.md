# 评审修复：目录移动 / 剪切粘贴 / 目录工具栏

> 完成时间：2026-11-05 22:51:46
> 范围：仅本轮 `browse` 目录入口改造、移动资产、剪切粘贴与空格修复；范围外问题不动。

## 评审发现并已修复

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | **RAW-only 资产永远搬不动**：同目录判断只看位图，空集合 `.all()` 恒真 | 改为按**整个文件组**判断：位图看目标目录、RAW 看 `<目标>/_RAW/`；新增 RAW-only 移动与重复移动幂等测试 |
| 2 | **同目录粘贴会漏搬未加载的照片**：前端把本地没有路径的 id 过滤掉了 | 未加载条目照常交后端；后端对同目录幂等。新增 `photoDirOf`（`_RAW/` 折算）纯函数与测试 |
| 3 | **组织视图（跨库）拖动 / 剪切会拿当前库的 id 去操作** | 拖动落点与剪切/粘贴在组织视图下禁用；`canCut` / `canPaste` / `runMoveIds` 三处同口径 |
| 4 | **目标已有同名 `.xmp` 时可能覆盖**（尤其 Unix `rename` 覆盖语义） | 重名探测把侧车目标也算冲突，整组改 `_01`；新增「已有侧车不被覆盖」测试 |
| 5 | **锁定照片仍可被移动**，与回收站的一级锁口径不一致 | `relocate::locked_for_move` 过滤一级锁；锁定组报告失败且记录/文件都不动；新增锁测试 |
| 6 | **换库 / 离开浏览后剪切提示仍残留** | 换库清剪切；工作区卸载清剪切；flowbar 默认槽随之回空 |
| 7 | **移动成功后删除按钮不重新判定** | 工作区 `moveRevision` + 左列订阅，移动成功即作废旧结论并重查 |
| 8 | **删除确认可连点并发执行** | `doDeleteDir` 在 `busy` 时直接返回 |
| 9 | 需求拍板里的 **`F5` 手动刷新遗漏** | 新增 `browse.refresh` 命令（`F5`），浏览/组织视图分别刷新各自来源 |
