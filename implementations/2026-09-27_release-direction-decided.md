# 发行方向拍板落档（REVIEW R3-01）

完成时间：2026-09-27 14:29:21 CST

## 范围

崔总 2026-09-27 下午拍板三平台发行方向，并指示：PLAN 记录 Windows 主线（unsigned 发布到 GitHub，后续 MSIX 打通商店）；macOS 与 Linux 留在 FUTURE。本记录覆盖该决策在四个文件的落地（REVIEW.md / docs/release.md / FUTURE.md / PLAN.md）。

## 决策内容（人类拍板）

1. **Windows：unsigned 官网/GitHub Release 直下首发**（M5 主线不变）；**直下链走通后启动 MSIX 打通微软商店**，作为「零现金成本解决 Windows 安装体验」的主攻方向。
2. **macOS：暂缓**，等 Windows 版成熟（$99/年 无免费替代、unsigned 直下报「已损坏」不可用）。
3. **Linux：空闲时先行打包**（意向非承诺；开发/打包可在现有 WSL 完成，验收需真机/虚拟机）。
4. 既有结论维持：不买 EV；IV/OV 与 SignPath 仅作 Windows 直下签名后备。
