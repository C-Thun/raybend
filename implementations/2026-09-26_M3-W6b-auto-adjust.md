# M3-W6b 显式自动调整与机型曲线学习
完成时间：2026-09-26 03:49:14 CST

## 范围与文件

- `crates/raybend/src/develop/base_curve.rs`：缩略级 RAW 与直出位图的亮度分位数拟合、33 点加斜率差相似度、保守曝光/反差/饱和度建议。
- `src-tauri/src/base_curve.rs`：显式点击时解析资产的 RAW 与配对位图，拟合并在同机型档案中匹配或建新档；之后交给前端选档。镜头仍调用既有 `lens_match` 查询。
- `src/workspaces/editor/EditorWorkspace.tsx`、`src/features/editor/toolbar.tsx`、`actions.ts` 与命令目录：工具栏入口移到裁切左侧；只有 RAW、位图、品牌型号齐全、照片可编辑时启用。完成后一次提交选档、影调色彩建议和可靠镜头匹配；计算期间用户改动使迟到结果失效。
- `PLAN.md`、`plans/M3-W6b.md`、`design/editor.md` 和双语文案同步。镜头按钮继续显示所选信息或「选择镜头配置文件」，弹窗打开刷新推荐。

## 决策

- 只在点击时计算，照片载入、导入和切源都不自动匹配；无配对位图时按钮禁用。
- 固定分位数控制点降低噪声；曲线差阈值 0.045，阈内直接采用原档案曲线并增加命中计数，阈外建新档案。曝光限制 ±0.30 EV，反差 ±12，饱和度 ±10，避免强自动调整伤及画面。
- 自动调整复用已有 `editor.develop.autoAdjust` 命令；默认热键留空，避免误触。只改基础曲线和现有影调、色彩、镜头参数，不动用户曲线，也不碰 LUT/issue。

## 验证与遗留

- Rust 单测覆盖空/低反差输入、不同调性曲线的距离和参数范围；前端测试覆盖 IPC 快照、RAW/SOOC 载荷隔离。全套通过情况见同日 W6a 记录。
- Windows debug 完整构建与资源检查通过；未声称真实 GUI E2E。人类需用 RAW+直出成对照片确认按钮可用性、拟合效果、机型档案归类、镜头候选与响应时间。
- 直方图拟合只表达整体亮度，难以区分亮度相同但色彩风格不同的 SOOC；阈值 0.045 是初值，需真实跨机型/场景样本标定。重复对同一照片点按钮会累计匹配次数，计数目前表示拟合命中次数而非唯一照片数。
