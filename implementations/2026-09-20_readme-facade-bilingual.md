## 关键决策与理由

1. **开场白 = 付费焦虑叙事**（人类两轮修正后定稿）：先说市面相片管理软件的三种付费情形（太贵 / 按年订阅 / 价格合理但不稳定，来自 `prompts/features.pd` 原文），再给光伴的回答（完整工作流 + 本地 + 永远免费）。**不踩任何免费软件**，也**不做「我们不能 X」式的负面声明**（那是内部方向，不是对外话术）。
2. **不点名任何竞品**；不提快捷键/命令面板当门面（面向普通用户，吓跑人）；不提性能数字（无实测对比不吹牛）；不写状态与路线图（门面只说产品是什么，进度不在 README 里解释）。
3. **双语镜像**：中英内容范围逐段一致；语言切换行当前语言为纯文本、另一语言带链接（消自引用）。
4. **logo 取代 H1**：wide logo 自带 RayBend 字标，避免重复；中文名「光伴」进 tagline 行，两侧头部都可见。
5. 结构：居中头部（logo + tagline + 链接）→ 为什么做光伴 → 功能 ×8 → 下载 / 从源码构建 / 技术栈一行 / 许可。技术细节只出现在「技术栈」那一行与构建命令里，功能区零技术词。
