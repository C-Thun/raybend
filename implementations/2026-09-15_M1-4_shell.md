## 3. 关键决策与理由

### 3.1 「要不要画三键」问运行时，不问配置

Linux/WSL 的配置保留了系统标题栏（§5 遗留 3），于是「该不该画我们自己的三键」就不能靠常量判断 ——
否则两个平台必然漂移。判定改成读窗口自己的 `isDecorated()`（**免权限**，`core:default` 里就有 `allow-is-decorated`）：

```text
在 Tauri 且窗口无系统标题栏  → 画拖拽区与三键
在 Tauri 但窗口有系统标题栏  → 只画图标/名称/菜单/主题/密度（不画三键，免得两套按钮）
不在 Tauri（浏览器）        → 同样不画三键
```

读 `isDecorated()` **失败**时按「沉浸式」处理 —— 更坏的失败是「既没有系统标题栏、我们也没画三键」，
那样窗口就关不掉了；多画一组按钮最多是难看。

### 3.2 菜单必须「钉住」

菜单弹层在 portal 里（DOM 上不在标题行内），鼠标移进菜单会触发标题行的 `pointerleave`。
不钉住的话，**菜单会在用户点它的那一瞬间自己关掉** —— 这类 bug 手动点击时很难复现清楚。
所以 `Menu` 新增 `onOpenChange`，外壳在菜单展开期间把可见性钉住（`shell/store.ts` 有详细注释 + 单测覆盖）。

### 3.3 模块级 JSX 会让 Solid 报警（实测）

图标曾写成模块级常量：`const ICONS = { import: <IconFolder/> }`，结果页面刷出
**5 条** `computations created outside a createRoot or render will never be disposed`
（正好是 4 个工作流图标 + 1 个工具图标）。改为存**组件引用** + `<Dynamic>` 后警告消失。
这条是 `pnpm smoke:ui` 抓出来的（它把 console warning 也算问题）——否则会一路带进后续模块。

### 3.4 危险色（评审意见 1）

`--danger = #BF4E30`（微微偏橙的锈红）+ `--fg-on-danger = #F6F8F4`，两主题共用。实测对比度：
与深色条带 `#2a2d33` **2.86:1**、与浅色条带 `#edf0e9` **4.20:1**、其上浅色图标 **4.52:1**（过 AA）。
它靠**色相与饱和度**跳出来，不靠明度，所以在两种主题下都看得清。已登记 `DESIGN.md` §9.2 与变更记录。

### 3.5 关于弹窗的信息分层（评审意见 4）

品牌块（图标 + 名称 + `版本 · 通道 · commit`）→ 必要信息（版本 / 许可 / 仓库，可点外链）→
一句实话「你的照片与目录永远不会被改动」→ **调试信息仅在 dev/test 包出现**
（构建时间、运行环境含 WebView 版本、commit 是否 dirty）。
判定依据是**构建通道**而不是 UI 开关：正式包的用户不该看见 commit，支持人员需要看见。

### 3.6 发版脚本只做准备（评审意见 4）

`pnpm release <test|patch|minor|major> [--channel beta] [--dry-run] [--allow-dirty] [--skip-build]`

- 版本语义放在纯模块 `src/lib/release-plan.ts` 并有 20+ 用例：`test` 不动版本号；
  `patch/minor/major` 从预发布**定稿**而不是再跳一级；beta 通道在**同一条 beta 线上递增**
  （否则会对同一个版本号印两遍 —— 这是写测试时抓到的真 bug）
- 正式包在**脏树上直接拒绝**（除非显式 `--allow-dirty`）
- **不 commit、不 tag、不 push、不出安装包** —— 计划里带 `humanCommands`，逐条打印给人执行
  （`AGENTS.md` §2.1：发布与推送必须由人类执行）

## 6. 一个工具问题（供参考）

本次会话中，编辑器侧的自动修复（pi-lens autofix）多次把**我没有改动过的文件**重新缩进
（缩进变成 7 空格），让 `git diff` 混进大量噪声。已用 `git diff -w` 识别出纯空白差异的文件并回退
（21 个文件），只保留真正的改动。后续如果看到莫名的大 diff，可以先跑一遍：

```bash
for f in $(git diff --name-only); do
  [ -z "$(git diff -w --ignore-blank-lines -- "$f")" ] && echo "纯空白噪声: $f"
done
```
