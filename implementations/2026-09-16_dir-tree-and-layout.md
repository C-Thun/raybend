# 目录树统一、运行期刷新、左列可拖宽与比例持久化

完成时间：2026-09-16 14:50:07 CST

## 这一批改了什么（都来自真机反馈）

| 反馈 | 做法 |
| --- | --- |
| 「目录组件抽象成统一的，浏览时能关掉勾选」 | `features/source-tree` → **`features/dir-tree`**（组件 `DirTree`）。**勾选圈的有无由「传没传 `onToggleCheck`」决定**，不再加一个可能与回调矛盾的 `checkable` 布尔 |
| 「双击目录名展开/折叠」 | `TreeNode` 新增 `onDoubleClick`（Solid 的 DOM 事件名是 `onDblClick`，在组件内部映射）；`DirTree` 里只对**可展开**的行生效，且双击落在勾选圈上不算 |
| 「目录展开时实时扫、有点卡」 | 树**本来就只在首次展开读一次并缓存**（折叠再展开是秒开）；这轮额外做了两件事：<br>① **行对象按路径缓存身份** —— `<For>` 按对象身份做 key，每次摊平都造新对象会把**整棵树**的 DOM 拆了重建；<br>② 去掉行上的 `transition-colors`（滚动时鼠标扫过每一行都会触发 150ms 颜色过渡 = 持续重绘，手感发粘） |
| 「至少要给一个运行期刷新机会」 | 树 store 加 `refreshAll()`（**只重读展开着的目录、保留展开状态**）；`DirTree` 用 `refreshKey` 令牌接收刷新（按钮在面板头部，缓存住在树里，两边不用互相持有引用）；「来源」面板头部加刷新按钮（顺带刷新卷列表，插 U 盘也能看见） |
| 「左列要能横向拖宽，右边不给；所有把手比例要持久化、重启还原；左列要有最小宽度」 | 新增 `SplitStack orientation="horizontal"`；工作区改成横向 splitter（左列 `minSize: "220px"`、右侧固定不参与）；新增 `lib/layout-prefs.ts`（设备级、`localStorage`、**只记比例**、拖拽结束才落盘、读取时夹范围）；左列内部的「最近/来源」比例同样持久化。**原则**写进 `DESIGN.md` §8.6：**只给左侧加把手** |
| 「『按时间』放到缩放组件左边，别和目录名凑一起」 | `GridControlBar` 的中间只留「当前目录」，`按时间` 移入右侧控件组（紧挨缩放滑块） |

## 单测与断言

- `lib/layout-prefs.test.ts`：8 条（范围夹取、垃圾值回落、读写往返、换实例读回 = 模拟重启、存储不可用不崩）；
- `dir-tree/store.test.ts`：新增 2 条（`refreshAll` 只重读展开项且保留展开状态；外部新建的目录**刷新前看不到、刷新后看得到** —— 把「不做实时监听」这个取舍写成断言）；
- `pnpm smoke:ui` 新增：目录树两种变体的勾选圈有无、双击展开/折叠、滚动开销上限、刷新按钮在；
- 冒烟脚本自身加了一道**自检**：`evaluate` 的模板串里不许出现反引号写的注释
  （这轮踩了三次：注释里的反引号会把模板串截断，而 `node --check` 抓不到，报出的错跟真正原因毫不相干）。

## 遗留

- 目录树**没有虚拟化**：展开一个几万条的目录仍会一次渲染全部行。
  实测 43 行滚动的样式/布局开销是 0ms 级，所以现在够用；等真遇到超大目录再上虚拟化
  （与浏览侧的网格是同一个话题）。
- 刷新是**手动**的：文件系统监听（`notify`）仍在 `FUTURE.md` 里，属于后续里程碑。
