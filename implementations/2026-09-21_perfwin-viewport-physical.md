# perf-win 视口告警改按物理分辨率口径

完成时间：2026-09-21 06:20:15 CST

## 起因

人类两次真机采样的数据把口径问题暴露了：
- 第一跑 CSS 1862×1048 @ dpr 1.375 → 物理 **2560×1441**，已达 DoD 的 2560×1440，
  却因脚本拿 CSS 尺寸比对被误报「视口不达标」；
- 第二跑 CSS 1397×830 @ dpr 2.2 → 物理 **3073×1826**（200% 缩放屏，对上 §7.9 spike
  验证过的 dpr=2.2），比 2560×1440 还多 50% 像素，同样 120fps。

DoD 的「2560×1440」是**物理分辨率**口径，告警必须按 CSS×DPR 算。

## 改动

`scripts/perf-win.mjs`：视口校验改为物理口径（`round(inner×dpr)`，<2500×1400 才警告）；
报告 JSON 的 viewport 增加 `physical` 字段；控制台输出附物理尺寸。

## 验证

`node --check` 过。无需重跑：两次真机数据（06:00 与 06:10 的 JSON）已覆盖
「2560×1440@1.375 → 120fps」与「3073×1826@2.2 → 120fps」两种口径，60fps DoD
两屏均以约一倍余量成立（worst 19.9ms 为 360 帧中一次，占 0.3%）。
