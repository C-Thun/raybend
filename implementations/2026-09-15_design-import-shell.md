## 关键决策与实测发现

### 1. 令牌机制：颜色可用、尺寸不可用（重要）

**可用**：`fill` / `cornerRadius` / `padding` / `gap` 接受变量引用，且支持两条主题轴
`mode: light|dark` 与 `density: compact|loose`。

**不可用**：`width` / `height` 传变量会被**静默丢弃** —— 不报错，但读回是 `undefined`。
实测序列：字面量 `32` → 读回 32 ✓；`$bar-title-h` → 读回 undefined ✗。

**后果**：密度轴在 Pencil 里**只能表达颜色，不能表达尺寸**。
设计稿的尺寸按紧凑档硬写；「宽松」档需要另出一版。
已同步修正 `DESIGN.md` §8.2 与 §9.2 的说法（原写法夸大了主题轴能力）。

### 2. 主题可按节点设置 → 一张画布同时出深浅两版

给 frame 加 `theme:{mode:"light",density:"loose"}`，**整棵子树自动继承**该主题解析。
验证：浅色版是 `Copy` 深色版后只覆盖 `theme` 得到的，`TitleBar` 解析为 `#EDF0E9`、中列 `#EDF0E9` ✓。

这解决了「Agent 无法切换 Pencil 当前主题」的死结 —— 不需要用户手动切主题，两版可以并排看。

### 3. 面层级的实际效果（用户最关心的一点）

| 区域 | dark | light |
| --- | --- | --- |
| titlebar | `#2A2D33`（浅深色） | `#EDF0E9`（深浅色） |
| flowbar + toolsbar | `#202226`（深色） | `#F6F8F4`（浅色） |
| 工作区两侧栏 | `#202226`（深色） | `#F6F8F4`（浅色） |
| 工作区中央 | `#2A2D33`（浅深色） | `#EDF0E9`（深浅色） |

**结果符合预期**：flowbar 与 toolsbar 同面 → 连成一体；中央在**两种模式下都形成聚焦**
（深色下中央更浅、浅色下中央更深），且不需要任何分隔线。

### 4. 界面表达不出来的设计思路全部写进 `.md`

这是用户明确要求的（规则 5）。`design/main.md` 记录了这些静态稿无法承载的内容：

- **菜单只在鼠标指向标题行时显示**（稿里画的是显示态）
- **工作流是有序流水线**（不同于并列多选项），所以顺序固定、不因最近使用重排
- **Exif 分组是内容结构**（机型+镜头 / 曝光 / 尺寸），不是视觉切分
- **图片区的完整键鼠交互**（双击切换适应屏幕↔100%、滚轮平滑缩放、左上角浮出返回按钮）
- **排除的区间反转语义**：`Shift` 点击两点之间 → 未排除的被排除、**已排除的被反选**
- **`shortpath` 的实例对照表**（完整路径 ↔ 缩写）
- **`easy copy` 的 4 阶段行为**
- **「勾选」与「选中」两套独立状态的语义**（勾选可多选，选中全局唯一且跨面板同步）

### 5. 我做的三个判断（已在 `.md` §7 列为待确认）

| # | 判断 | 理由 |
| --- | --- | --- |
| 1 | 选中项用**品牌主色实色块**（工作流胶囊、密度胶囊） | 「当前选择」正是主色的用途；若太抢眼可改低透明度 |

**修掉的真实布局问题**（不是靠肉眼，是靠 `ctx.problems` 与 `ctx.bounds` 查出来的）：

1. 标题栏高度塌陷 —— `height:"$bar-title-h"` 被静默丢弃，导致父子循环 `fit_content` → 高度 0。
   改为字面量后修复。
2. 已选目录 tile 的「包含子目录」勾选行被裁切 —— 我按路径文字 2 行估算高度 78，
   实测部分路径折到 **3 行**（如 `D:\P\2\W\Wedding-Studio`），内容 90.5 > 78。
   改 tile 高 96、容器高 210 后修复。
3. 分隔条的 `...` 用文本绘制会被 9px 容器裁切 —— 改为 3 个 2×2 的圆点。

**遗留告警**：仍在 `TileRow / 1` 上报 `partially clipped`，但实测数据吻合
（行 96+96=192 ≤ 容器内容高 210），且深浅两版的截图都**看不到裁切**。判定为取整噪声，暂不处理。

**未验证**（诚实起见）：全部为**设计稿层面**的验证。
`.pen` 里没有任何可执行代码，**没有跑过任何前端实现**；`DESIGN.md` 的令牌数值也尚未在真实 `tokens.css` 中落地。
