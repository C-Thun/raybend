## 检查中发现并修复

1. rAF 方法挂在注入环境对象上直接调用，会在浏览器报 Illegal invocation；改成显式函数包装，保持浏览器正确接收者。纯 Node 注入单测无法独自发现，因此保留真实浏览器脚本回归。
2. 原生图片 dragstart 会抢走内部指针拖放；上方定稿区域阻止原生拖放，普通点选保持原语义。
3. 动态 class 在 classList 之后覆盖卡片边框；改成静态基础 class 与集中状态 classList。
4. 重名控件加入后，小窗口表单挤压预设列表，卡片中心落在裁剪区外，实际命中右栏容器；预设区最小 96px，设置区不足时内部滚动，保留完整卡片与固定操作/提示。
5. Windows canonicalize 会产生长路径前缀并规范分隔符，三个测试原来拿它与非规范化字符串比较而失败；按实际规范化路径断言，未改变业务路径语义。
