# 非默认层隐藏全局阶段页签；色彩管理去掉固定说明

> 完成时间：2026-11-01 22:54:25
> 来源：崔总 2026-11-01 真机截图（右栏非默认层挂着「当前编辑区域下不可用」，清晰度 / 镜头 / 色彩管理仍在）

## 1. 「当前编辑区域下不可用」整块删掉

`AGENTS.md` §2.20：界面不挂**不带变量的固定说明文字**。这条提示是典型违反：
它每次都一样、不解释「这一次」为什么不行，而且常驻在参数区顶部。

* `src/features/editor/panels.tsx`：删掉 `data-area-global-blocked` 那段 `<Show>`；
* `src/features/editor/lut-panel.tsx`：同一个提示与它的 `disabled` 入口一并删掉
  （LUT 本来就对任何层可用，那个 prop 没人传，属隐患）；
* i18n：`editor.area.globalUnavailable` 两种语言都移除。

## 2. 全局阶段只属于默认层 —— 不在默认层时**隐藏**，不是置灰

按 `specs/editor-area.md` §4.3，清晰度（降噪 / 锐化）、镜头、色彩管理、局部色调都是**全局阶段**。
之前只是把它们置灰 + 挂提示；现在改成**页签与控件整块不出现**：

| 位置 | 规则 |
| --- | --- |
| 影调页签组 | 非默认层只剩 `影调` / `色彩`（`清晰度` / `镜头` 从选项里过滤掉） |
| 影调组内的 `动态反差` | 它也是全局阶段（`target: global`）—— 非默认层不显示这一行 |
| 曲线页签组 | 非默认层只剩 `曲线` / `预设`（`色彩管理` 过滤掉） |
| 切层时的页签收敛 | 当前页签已不存在时自动退回 `影调` / `曲线`（分段控件不能指向不存在的值） |

实现是**从「当前层能不能用」推出来的列表**（`paramGroups()` / `curveTabs()`），不是维护三份写死的
列表 —— 以后再加全局页签只要标好 `target`。

## 3. 色彩管理面板删掉固定说明

| 删掉 | 说明 |
| --- | --- |
| `当前沿用旧版处理。应用输入将显式切换高精度管线…` | 固定说明（`inputPending`） |
| `选中照片后，这里会显示其输入色彩依据。` | 同上（`noPhoto`） |
| `输入依据已固化，可撤销修改。` | 同上（`frozen`） |
| 显示区第二行（`画布已采用当前屏幕的 ICC 转换。…`） | `DisplayColorStatus` 新增 `detail={false}`，编辑器里只留状态标题；设备设置页仍是完整版（那里是配置页，说明有用） |
| `RGB · 相对色度。只改变查看；复杂配置、纸白和感知模拟暂不支持。` | 整行删；「相对色度」改为**打样开关右侧的短提示**（`editor.colorManagement.intent`） |
| `打开面板、换屏或打样不重建照片缓存。…` | 整行删 |

对应 i18n key 两种语言一并移除，新增 `editor.colorManagement.intent`（`相对色度` / `Relative colorimetric`）。
