# 编辑会话管道 W6：收尾（结构收敛、文档、性能证据、真机验收清单）

## 一、两条显影路的骨架收敛（§8.1）

**已合并到一份实现**（legacy 与 V2 共用，测试锁住）：

| 骨架件 | 落点 |
| --- | --- |
| 何时重建源缓存 | `editor::source_needs_reload`（路径 / 源签名 / 显式照片任务 / 色彩状态） |
| 参照源解析与「SOOC 不可用」 | `develop::ReferenceSources` + `editor::reference_sooc_path` |
| 参照来源标签（`raw` / `sooc`） | `editor::reference_base_of` |
| 白平衡基线 = 解码真值 | `editor::params_with_decoded_baseline` |
| 过渡帧发射与接受 | `transition_outcome` / `accepts_transition` / `present_transition` |
| 任务合并、panic 兜底、通道 | `develop_loop`（本来就一份） |

**未合并**：两条路的**执行体**（取源 → 档位 → 局部色调分析 → 降噪 → 渲染 → 直方图 → outcome）
仍各自一份。理由（如实记录，非「已完成」）：

1. 两路的像素类型不同（`LinearImage`/`Rgb8` vs `WorkingPreview`/float Rec.2020），
   要做到「一个骨架 + 两个钩子」需要先抽象一层像素类型 —— 而 §8.1 明确「**不做像素路径合并**
   （V2 是未来主线）」，抽象层的收益与风险不成比例；
2. 这两段代码是编辑器最核心、真机手感最敏感的部分，本会话**无法做真机视觉验证**
   （§10.2），一次性大重构的回归风险不可控。

后续若要继续收敛，建议以「V2 全面取代 legacy」为路径（`memory/FUTURE.md` 的既有登记），
而不是把两条执行体缝在一起。

## 三、性能证据（§8.3）

本会话在真照片（`/mnt/c/src/tmp/pic/AM300135.ORF`，4608×3456，15.93MP）上实测：

| 项 | 数字 |
| --- | --- |
| RAW 线性解码（worker，含建库后） | **1267.5 ms** |
| 预览档（1920 边）整条管线 · 全部可选阶段 | 44.3 ms |
| 1:1 档整条管线 · 全部可选阶段 | 550.0 ms |
| 线性源缩到预览档 | 126.7 ms |

读数命令（可复跑）：

```bash
cargo build -p raybend --bin raybend-raw-worker
cargo run -p raybend --release --example develop-probe -- "<一张 RAW>"
```

**结论（Agent 侧可证的）**：过渡帧（读已存在的 1920 快照 + AVIF 解码，量级几十 ms）
省掉的正是那 **1.2s+ 的整解码 + 百 ms 级管线**；V2 的几何 / 参照操作不再重解码（单测锁定）。

**缺什么**：§8.3 要求「W1 前 / W2 后各记一份切图时序」—— W1 之前的代码在本会话开始时
已经不在工作区（同一会话连续实施），且真机照片库与 GPU 视口不在本会话可达范围；
**该对比留给崔总在 Windows 真机上按 §10.3 清单观察**，诊断行已就位：

```text
[editor] 过渡帧：<origin> WxH（逻辑 axb，原图 cxd）耗时 Nms；候选 M 个
[editor] 真帧：job #N 档 Preview WxH 解码 Nms 管线 Nms（整条 Nms）
```

## 四、真机验收清单（交崔总，§10.3）

- [ ] 裁切 / 旋转过的照片来回切：首帧画幅正确、无拉伸、无跳变
- [ ] 编辑过的照片：切回时首帧要么是同版本快照、要么是「载入中」（不出现别的版本）
- [ ] 未编辑照片：切图仍然快
- [ ] 切图体感：连续切 10 张（含 1:1、含大降噪设置），无明显「某张特别慢」
- [ ] 白平衡：调过白平衡的照片来回切，首帧颜色正确（无几秒跳变）
- [ ] 预设跨照片：套用到 as-shot 不同的照片，冷暖倾向一致
- [ ] 对比参照：SOOC / RAW / 定稿切换，标签与实际一致；无位图照片显示 `SOOC → RAW`
- [ ] 定稿（issue）：生成后立刻在对比 / 全屏里看到（不再长时间等待）
- [ ] 定稿自愈：手工删掉某定稿的缓存图后进 editor，图自己回来（且不闪）
- [ ] 缓存目录：反复编辑同一张 20 次后，`cache/full/<asset>/` 不会堆满
- [ ] **存量白平衡修复（§6.8）**：先看修复前后同一画面两张图再决定是否执行
      （命令：`cargo run -p raybend --release --example fix-as-shot-k -- "<库根>"`，默认只预演）
