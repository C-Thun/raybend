## 一、3.1 标记边界

* `features/browse/mark-feedback.ts`（新）的 `markNotice()`：**只在出问题时说话** ——
  被锁挡住（`skippedLocked`）报「N 张有锁，没有改动」，一个都没改也说一句；改成功则闭嘴
  （照片上的标记变化本身就是反馈）。带畸形响应韧性（IPC 给脏数据不白屏）。
* 「清空旗标」改走 **`easy destroy` 确认**（跨库跨目录的全局动作，值一次确认）。
  注意它用 easy destroy 而**删照片不用** —— 后者支持多选批量（人类 2026-09-19 的批注）。

## 二、3.2 标签（后端 + 弹窗）

标签分两处存（`AGENTS.md` §6.4）：**词典在 `app.db`**（名字、折叠名、使用次数，跨库共用）、
**归属关系在各库的 `catalog.db` 的 `asset_tags`**。

* `store/tags.rs` 新增三个函数 + 7 条单测：
  * **`search_tags`**：折叠名（NFC + 小写）子串匹配、空查询列常用、`use_count` 降序；
  * **`escape_like`**：用户输入 `%` / `_` / `\` 时**不当通配符**（不转义的话搜「50%」会命中全部标签）；
  * **`apply_delta`**：按差量同步 `use_count`（词典全局、关联分库，**单库重算必然算少**）；
    词典里没有的 id **静默跳过**而不是报错 —— 关联侧残留一个「已从词典删掉」的 tag_id 是正常可能的。
* 新命令 `tag_list` / `tag_ensure`（`src-tauri/src/tags.rs`）；`MarkingItem` 加 **`tagIds`**
  （顺带触发了仓库的 **DTO 契约测试** —— `dto-contract.json` 两侧对着断言，改一侧不改另一侧会被拦下）。
* `browse_mark` / `undo` / `redo` 三处都接 `sync_tag_counts`（**失败不影响已落库的关联**）。
* `features/browse/TagDialog.tsx`（新）：严格照画布 —— 单张可增可删（每个标签带叉）、
  批量只能加（不给叉 + 写明「想移除请切回单张编辑」）、**0.6s 防抖**输入即搜、上下键选结果、
  **没选任何结果时回车 = 创建新标签**（哪怕上面已有匹配 —— 人类特意强调的那条）。
  草稿式提交：一次「加三个、摘一个」= **一步撤销**；取消 = 整份丢掉。
* 已有同名的输入点「创建」时**复用词典里那条**，不建重复的（冒烟里专门有一条断言盯着它）。

## 三、3.3–3.5 筛选与排序

* `features/browse/filter.ts`（新，12 条单测）：chips 模型、单条摘除、条件计数、关筛选只清四组标记条件；
  **`filterFromSelection`** 实现人类点名的「爽用法」（选中一张 3 星红标图 → 打开筛选 → 直接筛出同类）。
  口径与引擎对齐：`rating IN (3)` 是**精确匹配**，不是「及以上」（画布上那句「3★ 以上」据此要改）。
* `FilterBar.tsx`（新）：chips（每条可单独摘掉）+「共 N 张」+ **两个以上条件才出现**的「任一 / 全部」
  （默认「任一」，人类 2026-09-18 定）。
* 筛选态从工具条的局部信号**收到 store**（`filterMode` / `setFilterMode`）—— 工具条与结果区都要读它。
* 排序 UI 放**底部控制条**（与「按时间」「缩放」同排）：五个键 × 升降，没开筛选时也能用。
  ⚠️ 这与画布 ② 的 `SortBar` 位置不同，**画布要在 6.2 同步**（不是为了偷懒：排序不是筛选的附属功能）。
* 3.6：高级筛选面板**不做**，已登记 `FUTURE.md` **H10**（引擎其实已支持那些字段，缺的是界面与分面计数）。

## 四、4.1–4.3 撤销/重做、提示、模态

* store 新增 **`undoState()`**：记住后端每次动作回的 `canUndo/canRedo/undoLabel/redoLabel`，
  工具条据此出按钮与「撤销：标 3 星」这类文案（**前端不猜栈里有什么**）。
* `components/ui/toast.ts` + `Toast.tsx`（新，9 条单测）：右上角、`--z-toast`、
  **容器 `pointer-events-none`**（不遮挡操作）、成功 `$brand` / 失败 `$danger` 边框、
  约 5 秒、最多 3 条、带「撤销」动作。逻辑与视图分开是因为 `node --test` 不认 `.tsx`
  （与 `thumb-queue.ts` 同一个理由）。
* 接线：打标（带撤销）、清旗标、撤销/重做本身、标签保存、删除结果。
* 模态统一：标签弹窗、创建子目录、确认类、删除失败清单都用 `Dialog` / `ConfirmDialog`。

## 五、5.1–5.2 删除与键盘

* `features/browse/keys.ts`（新，14 条单测）：事件 → 意图的纯映射；三个修饰键的组合一律不管。
* 键盘落地：网格里 `←`/`→` 移动「当前那张」（**并把它滚进视野**）、`0`–`5` 打星、
  `P`/`X`/`U` 旗标、`Delete`/`Backspace` 删除、`Esc` 取消选择；看图里的方向键/`Esc`/`Enter`
  由图看件自己接（它知道切哪张、怎么退）。
  * **冲突处理**：看图里 `0`/`1` 是既有的缩放快捷键（适配 / 100%）⇒ **数字打星只在网格里生效**，
    看图时打标用 `P`/`X`/`U` 与工具条。
  * `lib/virtual-window.ts` 新增 **`rowScrollTop`**（5 条单测）：把某行滚进视野的纯计算，
    已经看得见就一个像素都不动（否则每按一次方向键画面都抖）。
* 删除：**只走确认这一条路**（`ConfirmDialog`），**不给 Shift 快通道、也不用 `easy destroy`** ——
  人类 2026-09-19 的批注：删除支持多选批量，而 easy destroy 是给「不做批量界面、又要连续删单张」准备的。
  结果分三路说清楚：成功 / 被锁挡住 / 文件已不在，**失败清单逐条进模态**。

## 六、6.1 左右列宽度可拖拽

* `lib/column-resize.ts`（新，6 条单测）：夹取 + 取整 + **右列 `invert`**（手柄在右列左边，
  往右拖是把它缩小 —— 符号搞反的表现是「拖右边那根、左边跟着变」）。
* `lib/layout-prefs.ts`：新增 `browseLeftWidth` / `browseRightWidth`（**像素**，不是比例 ——
  侧栏宽度是人手定的，改窗口大小不该让信息栏跟着变宽窄）；上下限 220–520。
* 工作区两根手柄（`role="separator"` + 方向键微调 + 指针捕获，**松手才落盘**），
  与导入工作区同一套做法；看图「关左右」时手柄一起收起来。

## 七、这一波挖出并修掉的坑（都是真问题，不是风格）

| # | 现象 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 工具条里**旗标「留下 / 弃掉」、喜欢 / 不喜欢、两级锁共 5 个按钮从来没生效过** | `ToggleBlock` 用自己的 `onClick` 覆盖了调用方传的 `onClick`（`{...rest}` 在前）—— 点下去有 hover、能按下，就是什么都不做 | 调用点改用组件自己的 `onPressedChange`；`ToggleBlock` 加防呆（两个回调都调） |
| 2 | **删完照片，整个网格崩**（`TypeError: Cannot read properties of null (reading 'id')`） | Solid 编译把 `item() === null ? null : item()!.id` **拆成两次独立重算**：判空那次结果被缓存，分支里的 `item().id` 是新读的 ⇒ 数据在两次之间变 null 就炸 | 判空与取值放**同一次函数调用**里（`flagOf()`）；同类写法在 `BrowsePanels` 里还有（有 `<Show>` 护着，暂未复现，已记在这里） |
| 3 | 对比态下 `Esc` 关不掉 | 单张看图件此时**没挂载**，没人接这个键 | 外壳补一条：对比态 `Esc` → 关 |
| 4 | 双击进看图从来没打开过 | `onDblClick` 传给 `<Tile>` **不会被挂到 DOM 上**（它自己接管了 `onClick`） | 外包一层 `class="contents"` 的 div 挂双击（与导入网格同法） |
| 5 | 按回车进看图，画面闪一下就关 | 打开看图后，**同一个仍在冒泡的 keydown** 被刚挂上的看图件当成「回车＝退出」 | 网格 `stopPropagation` + 看图件 `if (event.defaultPrevented) return` |
| 6 | 侧栏宽度改了界面不动 | `layout-prefs` 的 `commit` 只比较两个旧字段 ⇒ 只有宽度变化时被当成「没变」吞掉 | 四个字段都比 |
| 7 | 色标的无障碍名是英文原值（`red`）；「不喜欢」按钮写着「弃掉」 | i18n 漏网（英文原值与借用旗标文案） | 新增 `labels.ts` 统一取文案；补 8 条键 |
| 8 | 冒烟脚本自己把假后端写坏了 | 注入的模板串里 `split("\n")` 变成了真换行，JS 字符串断开 | 改成截断，不再 split（自伤，记录备查） |

另外：`use_count` 的同步口径（词典全局 vs 关联分库）、`apply_delta` 对未知 id 静默跳过、
`markNotice` 对畸形响应的韧性 —— 这三处都是**先写测试才发现**的边界。
