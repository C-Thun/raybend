# 定稿行走两行结构：名称渐隐 + 动作列纵向对齐

崔总 2026-10-09 要求：定稿列表里每条恒为两行（名称 / 源图类型+日期），第一行宽度受限、
超出渐隐淡出不撑开结构，第二行宽度受控；改名与删除两个图标改成**纵向排列**（上=改、下=删），
与两行文字对齐，中间文字区因此更宽。

## 结构

```text
┌──────┬─────────────────────────────────┬────┐
│ 缩略图 │ 名称（单行；超长右端渐隐，不撑行宽）    │ ✎  │  ← 与第一行对齐
│      │ RAW · 2026-10-09                 │ 🗑 │  ← 与第二行对齐
└──────┴─────────────────────────────────┴────┘
```

* 文字列 `flex flex-col`，两行都是 `leading-5`（20px）⇒ 文字块 40px == 缩略图高 `h-10`；
  动作列 `flex flex-col`，两个按钮 `h-5`（各 20px）⇒ 40px。三块同高，所以「图标对齐文字行」
  是**算出来的**，不是碰巧对上的（改字号/行高时三处一起动）。
* 第一行**不撑宽**：`block overflow-hidden whitespace-nowrap` + `.fade-x-end`（mask 渐隐，
  右端 1.25rem 淡出）。没超出时渐隐区是空白、看不出来；不加省略号（省略号 + 渐隐会糊）。
  整名挂在 `title` 上，悬停可读全名。
* 第二行 `truncate`（宽度由列约束；真超长才截断并带省略号）——「宽度受控」按这条落实。
* 生成中的占位行照同一结构（无动作列，预览位是转圈）。

## 渐隐为什么用 mask（而不是沿用工具条那种背景色渐变）

`shell/ToolsBar.tsx` 的 `FadeEdge` 是「盖一层 `from-surface-main` 渐变」—— 那要求渐变色
**等于当前底色**。列表行的底色会随悬停/选中变（`state-hover` / `state-selected`），
盖一层就得每个状态配一份、错一个就露馅；mask 直接作用于文字自身，与底色无关。
新增 `src/styles/fade.css` 只放这一条语义类（附理由与用法），`src/index.css` 引入。
