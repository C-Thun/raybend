# Canonical built-in RGB profiles, version 1

These profiles were generated by raybend with Little CMS 2 from the standard
primaries and transfer functions in `src/color/icc.rs`. They are project assets,
not copies of vendor profiles. The profile date is fixed to 2000-01-01 00:00:00.

The application loads these exact bytes on every platform. Do not regenerate
them at startup: a different C library or platform serialization must not change
a portable profile identity. A deliberate change requires a new built-in version
and compatibility handling for already referenced content hashes.
