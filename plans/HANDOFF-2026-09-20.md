## 4. 这个 session 踩过 / 证伪过的坑（下一个 session **一定**先读这节）

### 4.1 「双击没反应」被证伪过两次，第二次才是真因

* 第一次：effect 里写 `zoom`，而 Solid **事件处理器里的 setter 不批处理** →
  另一个「维持适配」的 effect 立刻把它按回去。修法是**改成派生**（`manualZoom` + `fitId` 状态，
  生效倍率是 memo），不是加 `batch()` 盖住。
* 第二次（本 session）：**`<For>` 按引用认身份**，而 `compareCanvas()` 每次都返回新的落点对象
  （点第一下会 `focus()` → store 变 → memo 重算）⇒ **那一格 DOM 被销毁重建** ⇒
  真双击的第二下落在新元素上，**浏览器根本不发 `dblclick`**。改成 **`Index`**（按下标钉住 DOM）。
* ⚠️ **教训**：合成 `new MouseEvent("dblclick")` **绕过 pointer capture 与命中测试**，
  它给过我们**两次假绿**。冒烟里的交互断言一律用 `Input.dispatchMouseEvent`（真鼠标）。

### 4.2 Zag 的 dialog **不写 z-index**

`index.css` 里那套「按 Ark 的 data 属性赋 `--z-index` 变量」**只对 popper 系生效**
（menu / tooltip / select / combobox / date-picker）；**dialog positioner 实测 `z-index: auto`、
连内联都没有** → 弹窗只能靠 DOM 顺序，被工作区 `z-10` 的看图/胶片覆盖层压住。
修法：dialog 的 backdrop / positioner **直接**写 `z-index: var(--z-scrim|--z-modal) !important`。
新增 `--z-titlebar: 75`（标题栏在弹窗之上：沉浸式窗口要能拖/关）。

### 4.3 无头 Chrome **默认没有鼠标**

`(hover: hover)` / `(pointer: fine)` 都是 `false` → Tailwind 的 `hover:*` / `group-hover:*`
变体**整条失效**（怎么移鼠标信息条都不浮出，一度误判成 CSS 写错）。
`check-browse-boot.mjs` 的启动参数里已经加了
`--blink-settings=primaryHoverType=2,availableHoverTypes=2,primaryPointerType=4,availablePointerTypes=4`，
并且断言前先验 `matchMedia("(hover: hover)")`。**新写 hover 断言时不要删这两处。**

### 4.4 从测试里驱动「模块级单例」这条路不通

想用 `await import("/src/i18n/index.ts")` 调 `setLocale()` 来驱动语言切换 ——
**拿到的是另一个模块实例**（HMR 的 `?t=` 让 App 的实例与裸 URL 的实例不同），
改了它自己的信号，App 毫无反应（实测：模块里 `locale()` 变成 `en-US`，DOM 纹丝不动）。
⇒ 要驱动这类单例，**走 UI 路径**（真鼠标点菜单），别 import。

### 4.5 其它小而致命的

* **探针清理**：本 session 两次因为临时探针留在冒烟里（或漏改变量名）把绿变红 ——
  每次清理后**必跑** `node --check scripts/check-browse-boot.mjs`。
* **探针要能一眼看出结局**：把状态塞进 `problems.push(...)` 里一次读全，别逐条猜。
* **状态机假设**：`i` 档位是 **三态循环**（off→marks→marks-name→off），「还原」要按到位为止；
  照抄「按一次 i 回到 off」会错。
* **`overflow` / 焦点残留**：模态开关（Ark 的 inert/焦点归还）在无头环境里会留痕 ——
  弹窗那段断言**放在冒烟最后**，别夹在 hover/键盘断言中间。
