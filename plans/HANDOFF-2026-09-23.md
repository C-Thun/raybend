## 3. M3-W2 开工指引（下一站）

**目标（`PLAN.md` §M3-W2）**：编辑视口里出现**真实照片**，可缩放、平移、1:1、适合窗口。

### 3.1 已经为 W2 铺好的地基（**别推翻重做**）

| 地基 | 在哪 | W2 怎么用 |
| --- | --- | --- |
| 洞口事实（CSS 矩形 + DPR + 视口尺寸） | `EditorViewport` 上报 → `editor::EditorState` | 渲染线程从 `EditorState::snapshot()` 取，**不要在 Rust 里另算一份** |
| 坐标契约与数学 | `crates/raybend/src/render/viewport.rs`（`Viewport` + 全套单测） | 已有 zoom/pan/rotation/fit/clip/dpr 与命中测试，直接用 |
| wgpu 上下文与设备丢失恢复 | `crates/raybend/src/render/gpu.rs`（spike 已验收） | `build_device_resources` 是**唯一**建资源入口（设备重建必须整套重建） |
| 视口交互的现成参考 | `src-tauri/src/spike_viewport.rs`（1444 行，含独立窗口、心跳、报告） | 抄**结构与坑**，别抄诊断/报告那部分 |
| 前端只发意图的示例 | `src/api/spike.ts` 的 `SpikeCommand` | editor 的命令面按同一套「只有意图，没有坐标」 |

### 3.2 建议的施工顺序（每一步都能单独冒烟）

1. **主窗口透明**：`src-tauri/tauri.conf.json` 的 `main` 加 `"transparent": true`，其余窗口不动。
   ⚠️ 别忘了 `src-tauri/tauri.linux.conf.json` 是**整份窗口配置的 merge patch**（数组整体替换），
   改主配置的窗口字段时要同步它（`AGENTS.md` §5.3 第 6 条）。
2. **Rust 侧渲染线程**：`src-tauri/src/editor.rs` 增一个渲染线程（通道 + `Shared` 状态），
   从 `EditorState` 拿洞口；**线程 panic 必须捕获 + 重启 + 上报**（spike 的第 5.3 节事故：
   panic 打死渲染线程时界面照旧响应、图永远冻住）。
3. **照片进纹理**：解码走现有 `raw::worker`（隔离进程，`AGENTS.md` §6.3），
   内嵌预览优先、完整解码留 1:1；上传与降采样都在 Rust。
4. **与胶片带联动**：胶片带换一张 → 通知 Rust 换纹理（W1 的 `createEditorStrip` 已经把
   锚点接好了，加一条「锚点变了就发命令」即可）。
5. **视口交互**：滚轮缩放（锚点不漂）、拖动平移、`1:1` / 适合窗口；命中测试在 Rust。
   前端只发 `pointer_to_image` 所需的原始值。
6. **收口**：离屏像素回读证据（期望值**外部给定**，别让被测函数自己生成）+ 真机最短门槛
   （复位 → 1:1 → 十字缩放，这三步不过就停）。

### 3.3 三条最容易踩的（写在 §7.9，真机血泪）

1. **WebView DPR ≠ 系统缩放**：本机是 1.25 × 1.10 = **1.375**，别只取 `scale_factor()`；
2. **wgpu 的 layout / buffer / texture 都记着自己属于哪个设备**：设备重建后跨设备复用
   会在 `create_bind_group` 抛校验错 —— 那个 panic 会**打死渲染线程**；
3. **`Surface::configure()` 返回 `()`**：失败只能靠 `push_error_scope` 或 panic 看见，
   而本仓曾经**没装 logger**（要原文就装 `RUST_LOG`）。
