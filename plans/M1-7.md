# M1-7 — M1 收尾：三次演练 + 性能基线 + 验收交付

> 本文是 M1 最后一个工作单元的计划（§5.4：一次只规划一个工作单元）。
> M1 的完成定义见 `PLAN.md`；本文只做「怎么验、验到什么程度」。
>
> 起草：2026-09-16（M1-6 全部 15 步完成之后）

## 为什么是这五步

M1 的完成定义里有四条**必须拿证据说话**的：

1. 建库 + 导入 **5000 张**照片，**重启后状态保持**；
2. 网格出缩略图、**滚动不卡**；
3. **进程被杀** → 重启能续跑未完成的任务；
4. **迁移 / 备份演练**，含**故意损坏后的恢复**；
   （外加：一份**实测性能基线** —— 没有基线就没有「卡」的判据。）

前四条都是「万一没做到，用户会丢数据」的级别，所以不能只靠单元测试，要有**可重复执行的演练**。
本单元就是把它们逐条做出来、留下证据，然后把 M1 交给人类验收。

## 纪律

- 演练脚本**可重复执行**（`cargo run --example …` 或 `node scripts/…`），不是手敲一遍算数。
- 性能数字**必须注明载荷与环境**；9p / WSL 的数字**不代表真机**，只作回归基线。
- 测试数据用**合成小图**（真照片太贵：伤盘 + 占空间），用完删。
- 每一步做完写/更新 `implementations/` 记录（§5.2）。

## 步骤

- [ ] **1. 本计划文档**
      完成定义：文件存在，步骤与验收方式明确（就是本文）。

- [ ] **2. 崩溃恢复演练（可重复执行 + 证据）**
      做法：合成数据建库 → 开始导入 → **导入中途 `kill -9`** → 用库侧恢复入口检查状态 →
      再跑一遍同一批导入。
      要给出证据的断言：
      - a. 库目录里**没有名字正确却内容不完整的照片**（`.part` 残留可以有，正式路径不行）；
      - b. 重启后能识别「上次没收尾的批次」并把它的 `pending` 项当半成品（`stale_pending`）；
      - c. 重跑同一批：**不重复、不覆盖**，已导入的跳过、半成品续上；
      - d. `PRAGMA integrity_check` 通过，库仍可正常打开（升级路径不误触发）。
      完成定义：一条命令能跑完整套演练，输出逐条 `通过/失败`，全过。

- [ ] **3. 迁移 / 备份 / 故意损坏演练**
      要给出证据的断言：
      - a. 旧版本的库（`user_version` 落后）能升级到当前版本，**数据不丢**（升级前留快照）；
      - b. 快照放 `backups/`，**保留 7 份**（第 8 次会裁掉最旧的）；
      - c. **故意破坏** `catalog.db`（截断 / 改坏头部）→ 打开**报错拒绝**，**不静默重建**；
      - d. 把 `user_version` 改到未来 → **拒绝打开**并说清原因；
      - e. 从快照恢复后库能正常打开、数据与破坏前一致。
      完成定义：同上，一条命令跑完，逐条断言。

- [ ] **4. 性能基线（注明载荷与环境）**
      - a. 导入吞吐：N 张合成图，报 **张/秒** 与 **MB/秒**（含扫描 + 复制 + 入库 + 缩略图入队）；
      - b. 缩略图吞吐：复用 `examples/thumb-bench.rs`，报 **张/秒**；
      - c. 网格滚动：复用 `scripts/grid-bench.mjs`，报帧率/掉帧。
      完成定义：一份基线表（含载荷规模、机器、盘、WSL/真机），写进实施记录；数字附「不代表真机」的说明。

- [ ] **5. 5000 张规模的导入 + 重启后状态一致**
      做法：5000 张合成小图 → 导入 → **杀进程** → 重新打开库 → 校验计数与文件数一致。
      完成定义：照片数 / 文件数 / 序号计数 / 缩略图队列 四项一致，且第二遍导入全判重跳过。

- [ ] **6. 交付：实施记录 + 人类验收清单**
      - 更新 `PLAN.md`：M1 完成定义逐条对照（做到了什么、留给人类验什么）；
      - `ASSISTANCE.md`：把需要人类目视/真机验的 4 条摆清楚；
      - 实施记录若干篇（每个演练一篇）。
      完成定义：人类拿到清单就能自己跑，不用问 Agent「怎么看」。

## 不做的事（本单元边界）

- **不碰编辑/导出界面**（规格尚未由用户提供，见会话记录）；
- **不做真机（Windows）性能结论** —— 那属于人类验收；
- **不开始 M2 的任何内容**。
